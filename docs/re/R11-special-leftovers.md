## 요약
**풀린 것 (확정)**: ① **에디트** — 상태 29 는 팀 고르기(5×2 = 팀 0~9 만) → 기본 명단 보기(엔트리 편집기를 보기 전용 ed+0x330 = −1 로, '*' 타자/투수 탭) → OK 로 입력 팝업(StrMAINMENU[108], 모드 한글·최대 8바이트) → 확인 시 **선수 id 로 이름표**(save[+0xac]+0x178, 9바이트 × 투수 80 + 타자 120)에 저장·파일 저장. 모든 이름 표시(0xb62c0, 26곳)가 "고친 이름 있으면 그것, 없으면 원래 이름" 이라 같은 id 의 복사본(시즌 팀·명전)에도 적용된다. 빈 이름은 확인 불가. **에디트 초기화 0x204c1 = 이름표 1800바이트를 0 으로**. ② **Q0 의 "상태 38 = 글 입력기" 는 틀림** — 0x2d370→0x26860→0x707a1 은 랭킹 서버(218.145.70.37:32206) 접속 🌐. 진짜 입력기는 [0x1552d00] 객체(모드 A/a/1/가, CLR 한 글자 지우기, 좌우 모드 전환, 한글 조합은 폰 플랫폼 호출) → 웹은 일반 input + CP949 8바이트 검사(이미 있는 `nameByteLengthOf`)로 대체. ③ **명전 삭제** — 선택지 선물/삭제, 삭제는 StrMAINMENU[128] 확인(예/아니오) → 칸 0x30 바이트 비움 + 시즌 팀 명단에서도 빼냄 → StrCOMMON[46]. **시즌 중 막기**(213 삭제·214 선물, 그리고 나리 초기화 212)는 모두 "그 선수가 시즌 내 팀에 있음 && 전역 +0x4e(시즌모드 경기 진행 중) ≠ 0". ④ **모드 목록 잠금** — 7칸 중 잠기는 건 **대전모드 하나**, 조건은 전역 +0x42(시즌 커리어 있음) == 0 → StrMAINMENU[115]. 최근게임은 마지막 모드(+0x3c)로 가며 미션·홈런더비면 고르기 화면(상태 17/16).

**남은 것**: 최근게임을 한 번도 안 했을 때(+0x3c = 0) 새 저장 기본값과 화면 동작(상태 39 가 갱신 없음 — 멈춤으로 보임, 미해결 한 고리) · 명전 선물(🌐)·0x5eae1 반환 1~4 의 정확한 뜻 · 입력 팝업 안 좌표 인자 일부 · 한글 조합 플랫폼 API 이름(웹엔 불필요).

## 3. 명예의 전당 선물·삭제와 "시즌 중 막기" — 상태 27 갱신 0x2ac00 · 키/팝업 0x62569 — **확정**

### 3-1. 흐름 (0x2ac00, this = 메인 메뉴, skin = [this+0x120])
- 전역 [0x1552cfc]+0xe4 == 0 이면 아무것도 안 함(입력 막힘 틱).
- **하위 상태 skin+0x126 (u8)**:
  - **0 = 슬롯 고르기**: `r = 0x62569(skin, 키, 0)` → skin+0x12c 에 결과.
    결과 0 → `0xbcb49(this+0x18, 6)` (스페셜 목록 상태 6 으로 돌아감). 결과 3·4 (등록된 선수가 있는 칸에서 OK, 유력) → 하위 1, 선택지 skin+0x128 = 0.
  - **1 = 선택지 2줄(0 선물 · 1 삭제)**: 위(−1·'2')/아래(−2·'8')는 0↔1 을 돈다(0x2aea6~0x2aec6). CLR(−16) → 하위 0.
    OK(−5·'5'): 칸 번호 idx = 목록 [this+0x74] 커서, 칸 종류 `0x5eae1(skin, idx)` 1·3 → **투수** 칸 (번호 idx−1), 2·4 → **타자** 칸 (번호 idx−6, idx>9 이면 idx−7).
- 선물(0)·삭제(1) 둘 다 먼저 **막기 검사**:
  ```
  0x213c1(save, 2, 1)                      ; 시즌 저장 적재
  team = 0x1f571(save, s8 [0x1f55d(save)+1]) ; 시즌모드 내 팀
  inTeam = 0xb50ad(team, 타자?1:0, 칸번호)   ; 명전 선수 id(칸 레코드 +0 바이트)가 팀 명단(+0x14 투수 / +0x18 타자, 0x30 간격)에 있나
  if inTeam && 전역기록(0x1f1d9)+0x4e != 0 → 막음
  ```
  - 전역기록 **+0x4c + 모드** = "그 모드 경기 진행 중"(경기 들어갈 때 1, R4·R9) → **+0x4e = 시즌모드(모드 2) 경기 진행 중**. 곧 "시즌 중" 이란 **시즌모드 경기가 중간 저장된 상태**이고, 그 선수가 시즌 내 팀에 들어가 있을 때만 막는다. 시즌이 진행 중이어도 경기 밖이면, 또는 팀에 없는 선수면 막지 않는다.
  - 막힘: 선물 → StrMAINMENU**[214]** "시즌모드 경기 진행 중에는 선물 보낼 수 없습니다", 삭제 → **[213]** "…삭제 하실 수 없습니다". 팝업 `0x74ef5(popup, 글, 종류 1)` + `0x74189`, 하위 상태는 그대로.
  - 통과: 선물 → StrMAINMENU**[127]**(선물 설명, 종류 2 예/아니오), skin+0x314 = **3**; 삭제 → StrMAINMENU**[128]** "현재 명예선수를 삭제 하시겠습니까? (삭제 시 복구 불가)" 종류 2 + `0x749d5(popup, 1)`(기본 커서 둘째 = "아니오" 로 보임, 유력), skin+0x314 = **4**. 하위 0 으로. 끝에 `0x1f24d(save, 2)`.
  - (StrMAINMENU 표 = [this+0x128], 0x702b5(표, 번호) — 번호 0x7f·0x80·0xd5·0xd6 이 그대로 127·128·213·214.)
- **StrMAINMENU[212] "시즌모드 경기 진행 중에는 초기화 하실 수 없습니다"** 는 같은 틀의 **나만의리그 초기화**(상태 33 0x2c6d8, 0x2c840~0x2c8fc): 타자편(하위 칸 0) → `0xb5055(시즌 내 팀, 1)`, 투수편 → `0xb5055(…, 0)` 가 참(시즌 팀에 그 편 나리 선수가 들어가 있음, 유력)이고 전역 +0x4e ≠ 0 이면 [212] 로 막고, 아니면 [210]/[211] 확인 팝업(종류 2). 곧 **"시즌 중 막기" 세 문구 212·213·214 가 모두 같은 조건(그 선수가 시즌 팀에 있음 && 시즌 경기 진행 중)** 이다. 웹판: `src/pages/settings` 에 나리 초기화는 있으나(K 5장) 이 막기는 없다 — 웹 시즌모드가 생기면 넣을 것.

### 3-2. 삭제 실행 — 0x62569 의 팝업 결과 상태 skin+0x314 (점프표 0xd1d24, 0~0x17)
- 0x314 == 4 → 0x62994: 팝업 결과 [0x140005c]+0x21c == 0(예) 이면
  - 투수 칸 → `0x22371(save, idx−1)`, 타자 칸 → `0x22339(save, idx−6 / idx−7)`.
  - 0x22339/0x22371: 칸 레코드 = save[+0xac] + **0x940**(타자) / **0x880**(투수) + 칸×0x30. 먼저 `0x221dc(save, 선수id, 종류)` — 시즌 저장이 있고(전역 +0x42 = 시즌 커리어 있음) 시즌 팀 명단에 그 명전 선수(0xb6349 명전 표시 && id 같음)가 있으면 **명단 끝 선수를 그 자리로 옮겨 빼낸다**(0x30 복사) — 그 뒤 칸 0x30 바이트를 0 으로(0x1400428 = memset).
  - 0x5eb8c(skin) 로 칸 다시 채움, 저장 0x1f1b9, 팝업 **StrCOMMON[46] "선수를 삭제하였습니다"** (표 [0x1552cf8] = StrCOMMON, 번호 0x2e), 0x314 = 0.
  - 결과 1(아니오) → 0x62e54: 0x314 = 0 만.
- 0x314 == 3(선물) → 0x62956: 통신 🌐 (읽지 않음).
- 판정: **확정** (함수·표·문자열 번호). 0x5eae1 의 반환 1~4 가 "칸 종류×등록 여부" 라는 해석과 0x749d5 의 뜻은 유력.

### 3-3. 웹판
- 명예의 전당 삭제·선물 자체가 없음(K-4 "삭제·투수 칸 없음"). 웹에 넣을 때 규칙: **삭제는 확인 팝업(기본 "아니오") 뒤 되돌릴 수 없음**, 시즌 팀에 들어간 명전 선수는 명단에서도 빠짐, **시즌모드 경기 도중 저장 상태일 때 그 선수는 삭제 불가**. 선물은 🌐 이라 뺀다.

## 4. 메인 메뉴 "게임모드" 목록 잠금 — 상태 5 갱신 0x28cb0 · 진입 0x25b88 — **확정**

### 4-1. 목록과 키
- 진입 0x25b88: 앞 상태가 4(메인 메뉴 첫 판)일 때 커서 [0x1552d24] = **0 (최근게임)**, 개수 [this+0xe9] = 7, 줄 위치 표 0xcea48 → 0x1552d28 (0x24 바이트). **항목을 숨기거나 건너뛰는 코드는 없다** — 7개가 늘 나온다.
- 갱신 0x28cb0: [this+0xe1] 켜짐 && [this+0xe2] 꺼짐일 때만. 키 [this+0x40]:
  - 위·왼(−1, −3, '2', '4') / 아래·오른(−2, −4, '6', '8') → [this+0x100] = −1 / −2, [this+0xf4] = 1 (바퀴 돌리기 애니) → 0x5550d. 잠긴 칸도 커서는 그대로 지나간다.
  - CLR(−16) → `0xbcb49(this+0x18, 4)` 메인 메뉴 첫 판.
  - OK(−5·'5'): 항목 id = 표 0xcebb0 `[11,12,13,14,15,16,17]`[커서] − 11 로 점프표 0xcebb8 (0x28d54 …):
    | 커서 | 항목 (그림 표 0xceb28) | 동작 |
    |---|---|---|
    | 0 | 최근게임 | m = 전역기록(0x1f1d9)+0x3c (마지막 모드) → [this+0x13c] = m. m ∈ {5,6}(미션) → 상태 **17**(미션 타자/투수 고르기) · m = 7(홈런더비) → 상태 **16** · 그 밖 → 상태 **39** (진입 0x32988 → 0x327b8(this, m): 모드별 이어하기/재시작) |
    | 1 | 일반모드 | [this+0xeb] = 0 → 상태 **12** |
    | 2 | 나만의리그 | → 상태 **13** |
    | 3 | 시즌모드 | → 상태 **14** |
    | 4 | 대전모드 | **전역기록 +0x42 == 0 이면 StrMAINMENU[115] "시즌모드를 먼저 시작해주세요"** 팝업(0x74ef5 종류 1 + 0x74189), 상태 그대로. ≠ 0 이면 [this+0xeb] = 0 → 상태 **15** (대전 통신) |
    | 5 | 홈런더비 | → 상태 **16** |
    | 6 | 미션모드 | → 상태 **17** |
  ```
  28dba: bl 0x1f1d9(save) ; adds r0,#0x42 ; ldrb r7,[r0] ; cmp r7,#0 ; bne 28dfc(→상태 15)
  28dcc: r0=[this+0x128](StrMAINMENU) ; movs r1,#0x73 ; bl 0x702b5 ; … bl 0x74ef5(popup, 글, 1, 0, 0, 0) ; bl 0x74189
  ```
- **전역기록 +0x40 + 모드 = "그 모드에 진행 중 커리어가 있음"** (R9: 나리 셋업 0xf684 가 +0x40+모드 로 이어하기 판단) → **+0x42 = 시즌모드(모드 2) 커리어 있음**. 0x221dc(명전 삭제 → 시즌 명단 정리)도 같은 +0x42 로 "시즌 저장 있음" 을 본다(3-2).
- 곧 **모드 목록에서 잠기는 것은 대전모드 하나뿐**이고, 조건은 "시즌모드를 한 번 시작해 커리어 저장이 있음". 히든 팀·마선수 해금(J·K)은 이 목록이 아니라 팀/선수 고르기 쪽 문제다.
- 최근게임: 커서가 막지 않는다. 기록 +0x3c 가 0(한 번도 안 함)이면 0x327b8 이 점프표(모드 1~9) 밖이라 저장(0x1f1b9)만 하고 돌아온다 — 상태 39 는 갱신 함수가 없어 화면이 멈춘 듯 보일 것(유력; +0x3c 의 새 저장 기본값은 확인 못 함 → **미해결 한 고리**).

### 4-2. 웹판
- `src/shared/config/original/mainMenu.ts:26-34` — 대전모드 isAvailable false(통신 🌐 이라 맞다). 넣게 되면 오프라인 대체판에서도 **시즌 커리어가 없으면 StrMAINMENU[115] 로 막는** 규칙을 쓴다.
- `src/pages/main-menu/model/mainMenu.ts:27-34` — 첫 커서를 저장 유무로 **최근게임/나만의리그** 로 고르고, 저장이 없으면 최근게임을 고를 수 없게 한다. 원본은 늘 커서 0(최근게임)에서 시작하고 잠그지 않는다(차이, 웹 쪽이 친절한 편이라 그대로 둬도 무방).
- 원본 최근게임은 **마지막 모드**(전역 +0x3c)로 가는 것이지 나만의리그 이어하기 전용이 아니다 — 미션·홈런더비면 그 모드의 고르기 화면(상태 17/16)으로 간다.

## 1. 에디트(선수 이름 변경) — 상태 29 진입 0x24804 · 갱신 0x2b2e0 — **확정**

### 1a. 흐름 (this = 메인 메뉴, skin = [this+0x120], 하위 상태 = skin+0xe6 (s8))
- 진입 0x24804: 팀 격자 [this+0x7c] 를 `vtable+0x1c(격자, 5, 2, 1, 0x10)` = **5열 × 2줄 = 10칸**, [격자+0x34] = 5·[+0x38] = 2, skin+0xe6 = 0, skin+0x84 = 1·+0x86 = 1, [skin+0xd4]+0xac = 1(능력치 도형 애니).

### 1b. 규칙
- **문구**: 팝업 그리기 콜백 0x32b7d 가 StrMAINMENU(this+0x128) **[109]** "아이디를 입력해 주세요 (한글 4글자, 영문 8글자) (통화료)" 를 기본으로 잡고, **this+0x181 == 1 이면 [108] "이름을 입력해 주세요 (한글 4글자, 영문 8글자)"** 로 바꾼다(0x32ba4~0x32bc8). 같은 창을 랭킹 아이디 등록(상태 37 0x2cd94)·대전(0x31918)·G선물/친구추천(상태 25·26)이 함께 쓴다.
  창 배치(유력 — 인자 뜻 일부 미확인): 문구 `0xba269(글, 화면크기/2 − 100, 0x82, 0xc8, 흰색)`, 입력 칸 = 폭 100 × 높이 15 를 (화면폭/2 − 50, y 0xaf = 175) 에 채움 RGB(30,45,160)(0x6b7d5) + 흰 선(0x541a9·0x541ed), 그 둘레에 [this+0x9c] 프레임 20·17 두 조각(0xba759). 입력 글자 자체는 입력기 객체가 그린다.
- **글자 수 = CP949 바이트 8**: 입력기 최대 길이 I+8 = min(8, 64) (0x54145), 저장도 `n = min(strlen, 8)` 바이트 복사 + NUL (0xaa4ad). 한글 2바이트·영문/숫자 1바이트 → "한글 4, 영문 8" 이고 **섞어 쓰기 가능**(예: 한글 2 + 영문 4). 한글 조합 중에는 잠깐 8 을 2바이트까지 넘을 수 있고, 조합이 끝나면 넘는 부분을 잘라낸다(0x67655, 2절).
- **빈 이름 금지**: 팝업 키 0x32b7d 끝부분 — OK(−5)는 `strlen(버퍼) != 0` 일 때만 확인(0x74361(popup, 0)), CLR(−16)은 버퍼가 비었을 때만 취소(0x74361(popup, −1)); 글자가 있으면 CLR 은 입력기의 한 글자 지우기(0x54279 → 0x66fd5).
- **고칠 수 있는 선수**: 격자 10칸 = **팀 0~9**(서울 드래곤즈 … 서울 게임빌즈·독도 스왈로즈) 의 **기본 명단**(0x1f8c1 = 저장 속 팀 레코드) 타자·투수 전원. 국가대표(10~13)·외인구단(14)·마선수·나리 선수는 목록에 없다. 다만 이름표는 **선수 id 로 걸리므로** 같은 id 를 가진 모든 복사본(시즌 팀, 명예의 전당 칸, 경기 명단)에 함께 적용된다.

### 1c. 저장 위치와 에디트 초기화 0x204c1
- 이름표 = 앱 데이터 save[+0xac] **+0x178**, 한 칸 9 바이트(8 + NUL):
  - 투수 id 0~0x4f(80명) → +0x178 + id×9 · 타자 id 0~0x77(120명) → +0x178 + **0x2d0** + id×9 (0xaa459: 범위 밖이면 NULL).

- 읽기: 선수 이름 함수 **0xb62c0(선수)** → `p = 0x20499(save, id, 0xb6278(선수) 투수?)` → `p && strlen(p) ? p : 선수레코드+1` (원래 이름). 부르는 곳 26곳 = 화면 전체의 선수 이름. 0x2046d(→ 0xaa489) = "이 선수에 고친 이름이 있나"(strlen ≠ 0).

## 2. 글 입력기 — **Q0 의 "상태 38 = 글 입력" 은 틀림** · 실제 입력기는 [0x1552d00] 객체(0x66f90~0x676e0) — 확정(구조) / 유력(한글 조합 방식)

### 2-1. 상태 38 (0x2d370 → 0x26860 → 0x707a1) = 랭킹 통신 🌐

  단계 0 → **`0x707a1(net, 10, 0)`** = 통신 시작: `loadingbar.pzx`(0xd24f4) 적재, `0x6cb61(net, "218.145.70.37"(0xd35a8), 포트 0x7dce = 32206)` 접속, 콜백 [net+0x284] = 0x32a99, [net+0x288] = this, 배경음 멈춤 0x6e459. 단계 1~3 은 net+0x70 상태(3 = 받음)를 기다려 결과 처리.

### 2-2. 진짜 입력기 — 객체 I = [0x1552d00]
| 필드 | 뜻 |
|---|---|
| I+4 (u8) | 켜짐 |
| I+8 (s32) | 최대 바이트 (≤ 64) |
| I+0xc | 모드 개수 · I+0x14 = **현재 모드** · I+0x18 + 모드×4 = 모드 이름 · I+0x10 = 직전 숫자키(멀티탭 판정) |
| I+0x28 | **입력 버퍼**(CP949, 최대 0x3d) · I+0x6c = 조합 중 버퍼 |
- 모드 이름 표 0x1400148 → `"A"`(0xd26b4) · `"a"`(0xd26b8) · `"1"`(0xcdbbc) · `"가"`(0xd26bc) = **0 영문 대문자 · 1 영문 소문자 · 2 숫자 · 3 한글**.
- 켜기 `0x54145(skin, 모드, 최대, 켜짐, 모드전환허용)`: 0x670d5(버퍼를 한 글자씩 지워 비움) → I+4 · I+8 = min(최대, 64) → `0x6714d(I, 모드, 1, 0)` → skin+0x2d1 = 모드전환허용.
  부르는 곳: 에디트 0x2b48c `(3, 8, 1, 1)` · 랭킹 아이디(상태 37 0x2d1b6) · G선물/친구추천(상태 25·26 0x2a7a8·0x2a534, 전화번호) · 대전 0x31918 · 명전 선물 0x62982. 나리·시즌 쪽 0xb8fc·0xbc44·0x17360 은 0x6714d 를 직접 부른다(선수 이름 짓기로 보임 — 이 절 범위 밖).
- 키 `0x54279(skin, 키)` (팝업 키 콜백 0x32b5d 가 부름):
  - 꺼져 있으면 −1.
  - **CLR(−16)**: 버퍼에 글자가 있으면 **한 글자 지우기** 0x66fd5, 비었으면 비우고 끔(0 반환 → 팝업 쪽이 취소로 처리).
  - **왼(−3) / 오른(−4)**: skin+0x2d1 이 켜져 있을 때만 **모드 이전/다음** 0x673ed / 0x673a9 (0 → 1 → 2 → 3 → 0 순환, 0x6714d 로 바꾸며 조합 중 글자를 확정).
  - **OK(−5)**: 버퍼가 비지 않았으면 조합 확정 `0x67655(I, 0x1f6, −5)` 뒤 2 반환.
  - 그 밖(숫자 '0'~'9', '*', '#'): `0x67655(I, 0x1f6, 키)`.
- 0x67655 → 0x67430(키 처리): 버퍼 길이 > 0x3d 면 CLR 만 받음. 모드 0·1(영문)은 직전 숫자키 I+0x10 과 같은 키인지로 **멀티탭**을 가리고 글자 변환은 역시 플랫폼 호출(0x14007e8)을 쓴다, 모드 2 는 숫자, **모드 3(한글)은 조합을 단말 플랫폼 호출 스텁 0x14007e8·0x14007d8 (ARM 스텁 → 공용 디스패처 0xcb2d8, 번호 507·302/304)에 넘긴다** — 한글 자판 배열(천지인/나랏글 등)은 앱 코드가 아니라 **폰 기종의 입력 자동기**가 정한다(유력: 스텁 모양까지 확인, API 이름은 모름).
  - 길이 제한: 모드 3 에서 길이가 최대를 넘고 최대 + 2 이하이면, 마지막 글자가 '.'·':' 이거나 조합 중 자모(선두 0xA4 + 0xA1~0xBE)·특수(0xA1 0xA4/0xA5)면 그대로 두고, 아니면 0x6762c 로 넘친 부분을 잘라낸다 → **조합이 끝난 한글 한 자가 8바이트를 넘기면 들어가지 않는다**.

### 2-3. 웹 대체 판단
- 원본의 멀티탭·모드(A/a/1/가) 전환·폰 IME 는 키패드 제약 때문에 있는 것이라 **웹에서는 그대로 옮길 필요가 없다** → 일반 `<input>`(브라우저/OS IME)로 대체. 이미 `src/shared/ui/TextField/TextField.tsx` + 나리 선수 만들기(`src/pages/create-player/ui/CreatePlayerScreen.tsx:50-53`)가 이렇게 하고 있다.
