**메뉴 6칸** (0x3b14 가 `0x6c219(메뉴, 6, 1, 1)` 로 만든 this+0x70. 키 0x8f30):
- 칸 번호 = `메뉴+0xc + 메뉴+0x10 × 메뉴+0x14` (0..5), 점프표 **0xcbe40** → `0xbcb48(sm, 상태)`:
  | 칸 | StrHOWTO[18] | 상태 |
  |---|---|---|
  | 0 | 시즌정보 | 0xcd |
  | 1 | 구단관리 | 0xce |
  | 2 | 트레이닝 | 0xcf |
  | 3 | 외출 | 0xd1 |
  | 4 | 아이템 | 0xd0 |
  | 5 | 다음경기 | 0xd8 |
- 칸 0~4 는 상태를 바꾼 뒤 `0x7ff54(this+0xc0)` 를 부른다(보조 UI 정리, 유력). `this+0xc0 +0x99 ≠ 0`(팝업 중)이면 키 무시.
- **취소(−16)** → 0x140006c = 5, `0xbc290(앱, 0x103)` = 메인 메뉴 장면으로 나감.
- 구단관리 하위 4칸 (this+0x78, 키 0x4e40, 확정): 0 구장관리 → 0xea · 1 트레이드 → 0xe4 · 2 선수영입 → 0xe2 · 3 코치채용 → this+0x11c=2, 0xd7.

**2경기 주기 (확정 — 0xf1 키 0x49a4, 0xcb 분기 0x4c24)**:
```
경기 뒤 흐름: 경기 장면 끝 → 장면 0x105 → 0xcb(phase 2) → 0xe9 관중·수입 → (0xd3 이벤트) → 0xf1 → 확인:
  포스트시즌(SR+0xb4) → 0xef
  SR+0xb2(이번 시즌 치른 경기 수) 가 짝수 → 0xc9 관리 메뉴
  홀수                                   → 0xd8 다음경기 (관리 메뉴를 건너뜀)
```
- 즉 관리 메뉴는 경기 수 0(시즌 첫머리)·2·4·…·44 뒤에 열린다 = StrHOWTO[18] "2경기마다 관리 메뉴". 45번째 경기 뒤(홀수)는 관리 없이 바로 다음 화면.
- 관리 메뉴의 "다음경기"(0xd8) → 확인 → ~~0xd7 선수단(엔트리) → 경기~~ **0xd7 마선수 고르기 → 0xdd 경기정보(좌우 → 0xe0 엔트리 편집) → 0xe1 → 경기** *(정정 2026-10-05, 메인 eefce6e)*. 다음경기 화면에서 **취소**하면 이전 상태가 0xc9 일 때만 0xc9 로 돌아간다(0x48ea).
