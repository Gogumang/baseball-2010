# 정정 모음 — 나중 해독이 앞 판단을 뒤집은 것

> 해독은 1차(A~L) → 2차(P·Q) → 3차(R) 순서로 했고, 뒤 문서가 앞 문서를 고친 일이 잦았다.
> **앞 문서를 읽을 때는 반드시 이 표를 함께 본다.** 각 문서 본문에도 *(정정)* 표시를 넣었지만 빠진 곳이 있을 수 있다.
> 교차 검증(V1~V5)은 188개 항목 중 178개를 확인하고 사용자 요청으로 중단했다 — **확인하지 않은 항목에도 비슷한 실수가 남아 있을 수 있다.**

## 1. "원본 버그" 로 적었다가 버그가 아니었던 것
| 처음 판단 | 실제 | 고친 문서 |
|---|---|---|
| A: 이벤트 490 이 질병을 **치료**한다 (보상 11 값 0) | 보상 글 만들기(0x8c14e)가 값 0 을 질병 종류 1~4 로 **다시 써서** 실제로 질병에 걸린다 | P4 → A |
| K: 돌발미션 "안타" 목표에서 **단타는 실패** | 결과비트 B5 = "타자 출루이고 이닝이 안 끝남" 이라 단타면 켜진다 → 단타도 성공 | P7 → K |
| G: 필살타법 레벨 4 에서 **표 밖 값**(380회·비용 0)을 읽는다 | 필살타법 창(0x17828)이 L=4 면 모든 칸을 StrMODE[63] 으로 막는다. 웹 '훈련완료' 가드는 원본과 같고 주석만 틀렸다 | R7 → G |
