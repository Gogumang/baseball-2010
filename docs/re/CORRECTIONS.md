# 정정 모음 — 나중 해독이 앞 판단을 뒤집은 것

> 해독은 1차(A~L) → 2차(P·Q) → 3차(R) 순서로 했고, 뒤 문서가 앞 문서를 고친 일이 잦았다.
> **앞 문서를 읽을 때는 반드시 이 표를 함께 본다.** 각 문서 본문에도 *(정정)* 표시를 넣었지만 빠진 곳이 있을 수 있다.
> 교차 검증(V1~V5)은 188개 항목 중 178개를 확인하고 사용자 요청으로 중단했다 — **확인하지 않은 항목에도 비슷한 실수가 남아 있을 수 있다.**

## 2-1. 새로 찾은 원본 버그 (나중 해독)
- **사람이 수비할 때는 협살이 절대 일어나지 않는다** (S8, 확정): 협살 시작 조건에 `state[0x31+state[0xa]] == 1`(수비 팀이 CPU)이 걸려 있다
- **2루 견제도 늘 3번 야수가 커버한다** (S8): 견제 시작 `0xb28be` 가 커버 야수를 "루 번호 + 1" 로 고정한다
- **목록 격자의 칸 x 가 어긋난다** (S9, 확정): `colW[col]` 이 아니라 **`colW[(i−1) mod 열수]`** 를 읽어, 열 너비가 서로 다른 목록에서 칸이 밀린다
- **마선수 레벨업에 최고 레벨 상한 검사가 없다** (S9): `0x5fb24` 안에는 없고 바깥 StrCOMMON[40] 에서만 막는다
- **중계가 낀 외야 재송구를 실제보다 짧게 본다** (S7): 재송구 틱에 `0xb3444` 의 `res[5]`(1구간 틱)을 그대로 쓴다
- `0xaff16` 의 `vt80[] = 0` 루프는 아무 효과 없는 죽은 코드 (S7)
- **야수선택이 퍼펙트를 안 깬다** (S5, 확정): 출루 허용 표시 `state[0x88]` 이 주자 목록의 **마지막 원소만** 보므로, 타자주자가 살고 앞 주자가 죽은 플레이에서는 출루가 안 잡혀 퍼펙트로 계산될 수 있다
- **시즌모드는 국가대항전 플래그를 안 내린다** (S6, 확정): `S+0x12c`(=`L+0xac`) 를 0 으로 쓰는 줄이 시즌모드 쪽에 **하나도 없다**(쓰기 15곳 전수 확인). 나리에만 있다 — 복붙 누락. 대회 뒤 정규 경기마다 재진입 `0x4b50` 이 대진표(243)로 샌다. ⚠️ **시즌 진행 불가급이라 "원본 그대로" 원칙과 충돌 — 사용자 판단 필요.** 다만 웹판엔 국가대항전이 아직 없어 당장 드러나지는 않는다
- **시즌 평판: 병살을 잡으면 평판이 깎이고, 탈삼진이 올려 준다** (S4, 확정): 점프표 `0xd7d7c` 가 코드 4·5 만 서로 뒤집어 놓아 병살이 `S[4]`(−2/3개), 탈삼진이 `S[5]`(+1/3개) 로 들어간다. **표 그대로가 실행값이므로 그대로 옮긴다**
- **세이브가 한 번도 기록되지 않는다** (S1, 유력): 세이브 종류 코드 state+0x64 를 0 으로 되돌리는 코드가 없어 경기 끝 검사(0xa7eaa)에 늘 걸린다. P1 의 "투수 실점 R+0x128 이 안 채워져 완투승이 늘 완봉" 과 같은 결
- **승리 투수가 없는 경기가 생긴다** (S1, 확정): 승리 투수는 6회 이후 득점 시점에만 정해져서, 5회까지만 점수가 나면 승리 투수가 비고 패전 투수만 남는다
