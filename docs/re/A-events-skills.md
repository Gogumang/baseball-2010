## 1. 구현 명세 — 게임에 넣을 것

### A-1. 이벤트 고르는 방식 (확정)
- **호출 시점**: 관리 화면(화면코드 105)·외출 지도(112)에 있는 동안 **매 갱신마다** 선택 함수를 부른다(0x1cdec). 통과한 이벤트가 있으면 이벤트 화면(0x72)으로 넘어갔다가 돌아온다 → 조건을 통과한 이벤트가 **하나씩 연달아** 모두 나온다.
- **선택 규칙**(0xadc70): 파일 순서로 훑어 **처음 통과한 한 건**. 우선순위·확률 없음. **커서를 이어 쓴다** — 다음 호출은 지난 당첨 위치부터, 끝까지 없으면 0 으로 되감고 그 호출은 "없음".
- 번호로 부를 때(0xae170)는 "현재 레코드 다음 위치"를 커서로 저장한다.
- **외출 장소 배정**(0x8cdc0, 지도 진입 때 한 번): 처음부터 훑어 trigger≥2 통과 이벤트마다 장소 = trigger−2, 빈 칸이면 넣는다 → 장소마다 파일 순서 첫 이벤트. 없으면 440+장소.
- **직접 호출**(0x8bdc8): 오프닝 451(새 선수, 0x8bde0), 분기(선택지·예/아니오·경기 결과), 연말 상태 132(13년차 504 / **1~6년차 380** / 7~12년차 502 — B-1 참고). *(검증 V1 정정: 노트의 "5년차 이하" 는 0-기준 idx ≤5 를 잘못 옮긴 것)*
- 웹: `src/entities/story/model/storyScene.ts` `nextEventFor` — 커서 이어 쓰기 없음. "분기 전용 63개 제외" 규칙은 원본에 없다(원본은 대상 0 으로 막는다).

### A-2. 판정 순서 (0xacfbc, 확정)
1. 대상 == 0 → 불발 (코드 호출 전용)
2. 모드별 허용 대상: 타자편(4) 1·2 · 투수편(3) 1·3 · 시즌(2) 4
3. id 490 이고 질병 쿨다운(+0x7c) > 0 → 불발
4. **본 이벤트면 불발** (반복 이벤트도. 반복 이벤트는 불러오기 때만 본 표시가 지워진다, 0xacf60)
5. trigger ↔ 화면: 0 ↔ {105, 201} · 1 ↔ 112 · ≥2 ↔ 113 (장소 인자 ≥0 이면 trigger−2 == 장소)
6. requiresEvent > 0 이면 그 이벤트를 봤어야 함
7. **날짜 창**: 바이트 a,b,c,d 중 **하나라도 0 이면 검사 생략**. `from=(a−1)·45+b`, `to=(c−1)·45+d`, `now=연차(0부터)·45+치른경기수+1`, `from ≤ now ≤ to`. 45 로 자르지 않는다.
   - 웹 `storyScene.ts` `isInDateWindow`: 연차 둘 다 0 일 때만 생략, 경기 번호를 45 로 자름 → **고칠 것**
8. 조건 목록(A-3). 조건 0개면 통과.

### A-4. 스킬 2~20 획득·해제 조건 (확정 — 카운터 이름 일부 유력)
표는 4절 상세 근거에 있다. 구현에 필요한 새 상태:
- `+0x70~+0x74` 연속 훈련 카운터(해당 칸 훈련이면 ++, **다른 훈련이면 전부 0**), `+0x75` 몹쓸몸 훈련 수, `+0x76` 유리몸 훈련 수
- `+0x1c0/+0x1cd` 먹튀 보유 중 인기도 변화 합·경기 수(먹튀 없으면 0)
- `+0x1c2` 이번 시즌 인기도 변화 합(경기마다 += 인기도 변화, 새 시즌 0)
- `+0x1c7` 무력감 보유 중 "경기 뒤 사기 ≥ 90" 연속 경기 수
- `+0x1d0+k` **마이너스 스킬 k 를 한 번 해제했음** → 다시 못 얻는다 (표 0xd7e10 = [2,3,4,5,17,18,19,20], 웹 `gpItems.ts:68` 과 같음)
- `+0x4b+i` 통산 훈련 칸별 횟수 / `+0x6b+i` 새 시즌 시작 때 사본 → 차이 = 이번 시즌 훈련 수
- 투수편: 스킬 비트 n(≥8)의 이름은 StrCOMMON 스킬 n+16
- 스킬 보상을 받으면 알림 팝업 (0x8d6bc)

### A. 이벤트 발동 조건 · 보상 · 스킬 (binary.mod 역분석)

#### 요약

이벤트 판정 함수 0xacfbc 를 끝까지 읽었다. 조건 종류 0~25 는 모두 식까지 확정했다. 20/21 은 "스킬 v−1 을 가졌는가"를 먼저 보고, 이어서 스킬 번호별 하위 switch(0xd8408 획득 19칸, 0xd8454 해제 19칸)로 간다. 스킬 2~20 의 획득·해제 조건을 카운터 수준까지 풀었다.
이벤트 선택(0xadc70)은 **파일 순서로 훑어 처음 통과한 한 건**이다. 다만 커서를 이어 쓰므로 매번 처음부터 훑지 않는다.
호출 시점은 세 가지로 확정했다.
- 관리 화면(105)·외출 지도(112) 상태에서 매 갱신
- 외출 지도에 들어갈 때 장소별 1건 배정
- 코드가 번호로 직접 부름(0x8bdc8)

보상 0~20 을 전부 풀었다. 21 은 엔딩이다. 393~396 은 연차 보정이 붙는다. ~~이벤트 490 의 질병 보상은 원본 코드로는 "치료"가 된다.~~ *(정정: 원본도 질병이다 — 보상 글 0x8beb8 이 값 0 을 0xbfa55(0, 4) + 1 로 다시 써 둔다. P4 · 메인 682d4de)*
화면효과 1~7 은 다음과 같다.
- 1: 진동
- 2: 진동과 흔들림
- 3: 흔들림
- 4~7: 흑/백 페이드

초상화 바닥선도 풀었다.
남은 것:
- 경기 내 카운터(+0x1f0 배열) 일부 칸의 뜻
- 타석 기록 코드 5~9 의 정확한 뜻
- 관리 화면 초상화 y 의 실제 수치

#### 0. 구조체 메모 (이 문서에서 쓰는 이름)
