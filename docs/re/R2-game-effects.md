## 2. deadly_effect.pzx (게임+0x1024) — 필살기와 **무관**, 수비 중 공 위치 번쩍임 (연결·좌표·순서 확정 / 트리거 뜻 일부 미해결)
**결론**: deadly_effect 를 읽는 함수는 0x4403c·0x441c4·0x44398 셋뿐이고(xval 0x1024: 그 밖엔 적재 0x48658 과 0x332b8 해제), 셋 다 필살 번호(선수+0x18)·필살 그림 칸(+0x1034/+0x103c)을 읽지 않는다.
세 함수는 경기 틱 0x46c88 이 0x46e08·0x46e0e·0x46e14 에서 차례로 부르는 **수비 장면의 공 번쩍임 상태 기계**다. 필살 연출은 H2 2-3(0x49aec 그림 + ptc)이 전부다.

- 공통 단계 칸 **+0x1992**(s8, −1 = 쉼). 각 함수는 자기 켜짐 바이트가 0 이면 바로 끝.

- "확대" 단계: **0xbb39d(100, 공x, 공y, 1, 0)** — 전역 0x15606d8 에 [0]=1, [1]=1, [4]=100, [8]=+5 를 넣는다. 읽는 쪽 0xbb84c 가 틱마다 [4] += [8], 110(0x6e) 을 넘으면 110 에 멈추고 방향을 바꿔(−5) 100 으로 돌아오면 끝낸다
  → **화면을 공 지점 중심으로 100→105→110→105→100% 로 한 번 튕기는 줌 펀치** (배율 뜻은 유력, 식은 확정).

### 3-2. HOMERUN 글자 연출 — 이미지 54~60 (확정)
