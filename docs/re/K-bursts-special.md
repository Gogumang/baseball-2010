- 파일 경로 문자열: data/XlsBATTER_BURST.zt1 0xd50b4 · PITCHER 0xd50d0 · SEASON 0xd50ec → 로더 함수 0x8e1b0 (리터럴 0x8e2c0~0x8e2c8)
- _TEXT: 0xd5178/0xd5198/0xd51b8 → 0x8eba0 (+0x8e5b8)
- 문구: 0xd5108 "!C!cffffff[", 0xd5114 "!cffff00돌발미션 성공!!", 0xd512c "…돌발미션 실패!!" → 0x8e5b8 에서 사용
- 행 수: 타자 40 · 투수 44 · 시즌 56. 행 크기 16, 열 16 모두 u8(타입 0). JSON 의 names 는 행 바이트를 잘못 읽은 쓰레기.
- _TEXT: 행 520 = (u8 화자, u8 표정, 문자열 128) × 4줄. 줄 0 제안 · 1 성공 · 2 실패 · 3 (아래에서 판정)
- 풀어 쓴 표: scratchpad/k/bursts.txt (행 바이트 + 네 줄 대사)

##### 1-1. 로더 0x8e1b0(obj, 모드) — 확정
- obj+0x22a = 모드. 모드 4 → BATTER(행 40) · 3 → PITCHER(44) · 2 → SEASON(56). obj+8 = 행 수, obj+0x10 = 표.
- 초기화: obj+0xc(현재 돌발 행) = −1, +0x21c = −1, +0x220/+0x221 = 0, +0x224 = 0, **+0x228 = 0 (이번 경기 발동 횟수), +0x229 = 1 (경기당 최대 발동 횟수)**.
- 호출: 0x48658 (리터럴 0x48d24).

##### 1-2. 발동 판정 0x8f158 → 후보 고르기 0x8f000 — 확정
- 0x8f158: 현재 돌발이 없고(+0xc == −1) **발동 횟수(+0x228) ≠ 최대(+0x229 = 1)** 일 때만 0x8f000 을 부른다 → **한 경기 최대 1회**. (호출지 0x509a0 — 타석 시작 쪽으로 보임, 미확인) *(정정 2026-10-05, 메인 bd4279a: 호출지는 **0x50d8c 한 곳** ← 0x50c42, 메시지 1 "확인" 의 인자 0xe 갈래뿐 — 1-6 참고)*
- 0x8f000: 행 범위 = 전체. **시즌 모드(2)** 만 `game[0x31 + game[0xa]] == 0` 이면 행 0~30(타자형), 아니면 행 31~55(투수형).
- 각 행에 대해 아래 검사를 모두 통과하면 후보 목록에 넣고, `rand(0, n)` 으로 **후보 중 균등 추첨** → +0xc = 행, +0x222(대사 줄) = 0, **+0x228 += 1**, 대사 로드 0x8eba0, 0x8e2dc, 효과음 0x2a.

  |---|---|---|---|
  | 상황 | 0x8ee3c | b0 | 아래 표 |
  | 주자 | 0x8ede8 | b1·b2·b3 | 1·2·3루: −1 무관 · 0 비어야 · 1 있어야 (0xa97a1(field, 루)) — b0 == 2 이면 건너뜀 |
  | 아웃 | 0x8ec3c | b4 | −1 무관, 아니면 game+6(아웃 수) == b4 |
  | 점수차 | 0x8ed50 | b5 | 0 무관 · 양수 k: 1 ≤ (우리−상대) ≤ k (이기는 중) · 음수 −k: 1 ≤ (상대−우리) ≤ k (지는 중) |
  | 경기 기록 | 0x8ec9c | b6·b7 | b6=0 무관 · 1: 현재 타자 이번 경기 안타(기록+0x12) == b7 · 2: 홈런(+0x13) == b7 · 3: 투수 0xb8ced(...)[0](이번 경기 탈삼진) == b7 |

- 점수차 '우리/상대' 는 game+0x32 로 고른 두 팀. 대사("역전 홈런", b5 = −2 + 주자 1·2루)로 보아 b5 는 **사용자 팀 기준**(유력: game+0x32 가 반 이닝인지 사용자 쪽인지 미확인).

##### 1-6. 발동 시점·경로 — 확정
- 돌발 객체는 경기 장면 생성 0x48658 에서 **게임 모드 2(시즌)·3(나만의리그 투수)·4(나만의리그 타자)** 일 때만 만든다 (`모드−2 ≤ 2`, 0x48c08). 장면 +0xf28 에 둔다.
- 장면 상태 0xf(타석 준비) 에서 +0xf28 이 있으면 0x8f158 → 발동하면 상태 0x1b(돌발 창)로 간다 (0x50c42~0x50c56).
- 즉 **상태 0xf 를 지나는(사람 장면) 타석 시작마다 후보를 모으고, 각 행마다 b9% 주사위**, 통과한 것 중 균등 1개. **경기당 최대 1회**. *(정정 2026-10-05, 메인 bd4279a: 예전 "매 타석 시작 때" 를 자동(0x21) 타석까지로 읽으면 틀린다 — 아래 1-6a)*
- 창: 줄 0 제안 대사 → 타석 → 결과 줄 1/2/3 + "돌발미션 성공!!"/"돌발미션 실패!!" (0xd5114/0xd512c, 0x8e5b8). 보상 적용 0x8e34c.

##### 1-6a. 자동(0x21) 타석은 굴리지도 판정하지도 않는다 — 확정 (메인 bd4279a, 호출지 전수)
- **0x8f158(발동) 호출지 1곳**: 0x50d8c ← 0x50c42 — 메시지 1 "확인" 의 인자 0xe 갈래(0x50c26 에서 0xf 를 **예약만** 하고 → 굴림 → 뜨면 0x1b 로 덮음). 0xe 는 0xd 에서만, 0xd 는 판정 A·B·C(0xae24c·0xae3e8·0xae3a0)의 "다음 타자" 로만 온다 — 모두 사람 장면.
- **0x8f414(판정) 호출지 2곳**: 0x4e7ca(0x12 갱신 0x4e6d4 끝) · 0x52a8e(0x17 인플레이 끝 0x528b0). 둘 다 사람 장면.
- **0x8f628(내림) 호출지 2곳**: 0x21 진입 0x3abf0 · 0x18 진입 0x3ac90(경기가 안 끝났고 아웃 > 2 로 뒤집힐 때). obj+0x21c = −1, obj+0xc = −1 만 쓴다 — 발동 횟수 +0x228 은 그대로, 굴림·보상·대사 없음. → 내 타석에서 결과비트 0 이나 목표 5 로 남은 돌발은 다음 0x21 진입·반 이닝 뒤집힘에서 **판정 없이** 내려간다(팀 경기도 같다 — 메인 afec7d4).
- 간이 엔진 0xc262c · 0x21 갱신 0x48480 의 호출 그래프(8단, 풀 함수 포인터 포함)에 셋 다 없다.
- 다음이 자동인지: 타석 끝 0x4e7ae · 0x528b0 → 0x35108 → 0x350d4 가 0xc1e04 참이면 다음 상태 +0x1b6c 를 0x21 로 덮는다.
  모드 4(0xc1ed6): 공격 팀 지금 타자가 내 선수가 아니면 자동 → 동료 타석·상대 반 이닝은 늘 0x21. 모드 3(0xc1eac): 우리 공격은 늘 자동, 수비는 지금 투수가 내 선수일 때만 사람.
