### B-3. MVP (시즌 MVP, 확정)
```
MVP = (타이틀 ≥ 1) AND (타이틀 3개 모두 OR 올해의 목표 달성 수(단계 2) ≥ 4)
```
- 단계 2 = 목표치 5개 모두 **+trunc(g·10/100)** 상향(투수는 방어율·+0x22 만 −10%)
- MVP 면 `career+0x1ca |= 1 << 연차idx` (연도별 MVP 비트, 통산 MVP 수 = 비트 수)
- MVP 가 아니면 내가 못 딴 첫 타이틀의 수상자를 MVP 로 보여 준다
- 웹: `app/model/seasonEvents.ts:29` `TITLE_RANK = 0`, MVP 없음

#### 1. MVP 판정 — **확정** (시즌 MVP)

흐름: 이벤트 375 "MVP 선발만 남았어" 안의 `system sub 4` → 0x8b23c(MVP 발표 창, StrUSER_EVT[83] "페넌트레이스 MVP",
내 선수면 [84] "축하합니다") → 이벤트가 끝나면 0x8cf64 가 0x8b370 을 불러 다음 이벤트를 고른다.
- 0x8b370: 나만의리그면 `evt+0x388 ? 377 : 376`, 시즌모드면 `? 379 : 378` (s_event 번호).

판정 함수 0x8dd60 (호출: 나만의리그 흐름 0x19774, 시즌모드 0xe7ac). 나만의리그 쪽(0x8de38~):
```
0x8de4e  bl 0x8dad4(evt, mode4 ? 0xc : 0xd)       ; 타이틀 다시 계산 (아래 2번)
0x8de58  ldr r2,[evt+0x36c]; tst r2,#0xffffff ; beq 0x8df18   ; 타이틀 3칸이 모두 0 → MVP 아님
0x8de60~ byte[0x36c] && byte[0x36d] && byte[0x36e] → MVP        ; 타이틀 3개 독식
0x8de84  else r0 = 0xa3de8(career, 2); cmp r0,#3; ble 0x8df18   ; 목표 달성 수 ≥ 4 여야 MVP
0x8ded2  MVP: evt+0x388 = 1, +0x370 = career[1](팀), +0x374 = 내 선수 이름, 0xa4d2c(career, career[+0xb3]) 호출
```
즉 **MVP = (타이틀 ≥ 1) AND (타이틀 3개 모두 OR 올해의 목표 달성 수 ≥ 4)**. 이벤트 376 대사
("우수선수가 되었는데도 선정되지 못했다면 올해의 목표에 더욱 충실해봐")와 맞는다.
- 0xa3de8 의 둘째 인자 2 는 392 평가(인자 0)·중간평가(1)와 다른 단계다 — 뜻은 4번 항목에서 확인 예정.
- MVP 가 아니면(0x8df18) 내가 못 딴 첫 번째 타이틀의 수상자(+0x30c[i] 팀, +0x31c+0x14·i 이름)를 MVP 로 보여 준다.
- 시즌모드(0x7b999 참): 표 0xd4f34 `[9,11,12,1,6,4,3]` 에서 무작위 종류 하나(rand 0..6)의 1위를 MVP 로,
  그 팀이 내 팀이면 플래그 1.
- 보상: 377 → 인기도 +20, 평판 +30, 소지금 +10(×100만).

웹판: `app/model/seasonEvents.ts:29` `TITLE_RANK = 0`, MVP 없음. `seasonFlow.ts:7-9` 주석 "아직 없는 것".

#### 2. 개인 타이틀 (370~374) — **확정**

흐름: 370 "누가 얼마나 잘했는지" 안의 `system sub 3` → 0x8b3bc(타이틀 발표 창) → 끝나면 0x8b04c:
나만의리그는 `371 + (evt+0x36c..0x36e 중 0 이 아닌 수)` → 371(없음)/372(1개, 소지금+3)/373(2개,+6)/374(3개,+10).

판정 0x8dad4(evt, kind): kind 0xc 타자, 0xd 투수. 칸 4개를 초기화(+0x30c[i]=10 "없음", 이름 0, 플래그 0) 후
- 타자 종류 표 0xd4f18 = `[9, 11, 12]` → 발표 문자열 StrUSER_EVT 0xd4e30 = `[76 홈런왕, 77 타점왕, 78 타율왕]`
- 투수 종류 표 0xd4f24 = `[1, 6, 4, 13]` → 문자열 +3 = [79 다승왕, 80 삼진왕, 81 방어왕]. 13 은 건너뜀(cmp #0xd).
  시즌모드는 넷째가 3(세이브, 문자열 82). 나만의리그 투수가 마무리(0x1fbd1→0xb6705 참)면 첫째가 3(세이브왕).
- 칸 i 마다 순위표 `0x9d789(obj, 종류, 선수타입(나만의리그 타자 4·투수 3·시즌 2), 1, 1)` 의 1위를 받는다:
  +0x30c[i] = 1위 팀(0x9da21), +0x31c+0x14·i = 이름, 플래그 +0x36c[i] = **1위가 내 선수인가** (0xb6389 = 레코드 +0xa 부호 비트).

##### 4-보충. 사건 코드 호출지 (뜻 미해결)
타석 기록 0xa8024 안: 안타면 코드 0(값=루타−1), `게임+0x25` 가 켜져 있으면 코드 4, `게임+0x13` 이 켜져 있으면 **코드 10(→G+0xf4, 평판 +1)**.
0xa8696 코드 12(→G+0xfc, 2 이상이면 평판 +1) 또는 3(→G+0xc8, 평판 +2), 0xa86dc 코드 1(→G+0xc4, 평판 +3), 0xa8a20 코드 15(값 r3 → G+0x108, 2 이상이면 평판 −2).
경기 끝 처리 0xa5c34(호출: 사람 경기 0x51408, 간이 경기 0xc0fb4·0xc1054)가 코드 18(G+0x114)·17(G+0x110)을 부른다(각 평판 +2).
`게임+0x13`·`+0x25` 가 무엇인지(대타? 2아웃? 득점권?)는 읽지 못했다 → **미해결**. 다음 단계: 0xa8680~0xa86e0·0xa8a00 앞 분기와 0xa5cc0~0xa5cf2 조건을 읽을 것.
경기 뒤 인기도(0xa690c)·사기(0xa73c4)는 RALPH 에 이미 있는 식을 이번에 다시 검증하지 않았다.

#### 요약 (최종)
**확정**: ① MVP 는 시즌(페넌트레이스) MVP — `타이틀 ≥1 AND (타이틀 3개 모두 OR 올해의 목표(+10% 상향) 4개 이상)` (0x8dd60).
② 개인 타이틀은 타자 홈런왕·타점왕·타율왕(투수 다승/세이브·삼진·방어율), 전 10팀 선수 기록 순위표(0x9d789, 규정 104타수·45이닝) 1위가 내 선수인지로 판정.
CPU 선수 기록은 CPU 끼리 경기가 사람 경기와 같은 기록 함수(0xa8024)로 쌓는다 — 웹판은 선수별 기록을 안 쌓아 이식하려면 그것부터 필요.
③ 국가대표는 홀수 년차(1·3·5·7·9·11) 연말, 올해의 목표 4개 이상이면 선발(0x1a090).
④ 평판 변화 뒷부분 = 평판 구간별 가감 보정표(0xd82a0/0xd82c8) + 뜻 모를 가산 6칸·감산 1칸.
⑤ 연봉은 100만 단위 저장·만원 표시("1억5000만"), 강경/정중 결과는 확률이 아니라 등급 k(타이틀 1위 수 + MVP 2)로 정해짐, 새 시즌에 소지금 += 연봉(상한 9999).
⑥ 엔딩: 부상 출전 20회(+0x1b6 > 19) → 부상 엔딩(아무 해나 경기 뒤), 연애 엔딩은 고백 이벤트 300~303 본 수로 10~14 (본 엔딩 뒤 덧붙음).
⑦ 목표표는 선수 +0xb 위 3비트(타입)로 고른다.
**미해결**: 평판 가산 칸 G+0xc8/0xfc/0x110/0x114/0xc4/0xf4·감산 G+0x108 의 사건 뜻, 국가대항전 경기(상태 134) 내용·보상, 상태 114/128 연결, 투수 평판 경로.
**웹판 차이 핵심**: 등급 k=0 고정(강경은 늘 −20%), MVP·타이틀·국가대표·연애·부상 엔딩 없음, 평판 구간 보정 없음, 목표표 0 고정.
