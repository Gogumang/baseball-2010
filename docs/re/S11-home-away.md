# S11 — 홈/원정(선공·후공)을 정하는 자리 `0xb7844` 와 `경기[0x28+side]`

S3 가 시즌 홈경기 구장을 이었을 때 **"포스트시즌·국가대항전에서 원본이 `경기[0x29]` 에 무엇을 넣는지"**
가 미확인으로 남았다. 이 노트가 그것을 떴다. 전부 **확정**(역어셈블 인용).

## 요약
- `경기[0x28 + side] = 팀번호` 이고, `side` 는 **`0xb7844(리그, 팀)`** 가 정한다. **1 = 홈(후공) · 0 = 원정(선공)**.
- `0xb7844` 는 세 갈래다: **국가대항전(`L+0xac`) → 포스트시즌(`L+0x34`) → 정규시즌** 순으로 검사한다.
  - **국가대항전**: 대진 **칸 0** 이 side 1. 풀리그는 칸 0 이 늘 대한민국이라 **대한민국이 후공**,
    결승은 칸 0 = `L+0xae` = 풀리그 **1위** 라 대한민국이 2위로 올라갔으면 **선공**.
  - **포스트시즌**: 대진 **칸 0(윗 시드)** 이 side 1. **차수에 따라 홈이 돌지 않는다.**
  - **정규시즌**: 일정표 `0xd89cb` 와 9일 주기 뒤집기 (R1 1절·웹 `leagueSideOf` 가 이미 맞다).
- **국가대항전 경기에는 시즌 구장이 안 나온다.** `0x40ff0` 이 `0xb6bdc(경기,1) == SR[1]` 로 보는데,
  국가대항전의 `경기[0x28+side]` 값은 **대표팀 번호 10~13** 이고 `SR[1]`(시즌 내 구단)은 0~9 뿐이라
  (히든 팀 10~14 는 **일반모드에서만** 고를 수 있다 — J-1) 절대 같아지지 않는다.

---

## 1. `경기[0x28+s]` 를 채우는 자리 — 전수 (확정)

세터 `0xb6bd4(st, s, v)` = `adds r1,r1,r0 ; adds r1,#0x28 ; strb r2,[r1]` → `st[0x28+s] = v`.
게터 `0xb6bdc(st, s)` = `(s8) st[0x28+s]` (S13 노트와 같다).

`bl` 로 안 가고 리터럴 풀에 `0xb6bd5` 를 담아 베니어 `0xca9fc`/`0xcaa00`/`0xcaa04` 로 간다.
값 `0xb6bd5` 가 들어 있는 리터럴은 **여덟 곳**뿐이고, 그것을 `ldr` 로 읽는 자리도 여덟이다:

| 리터럴 | 읽는 `ldr` | 함수 | 무엇 |
|---|---|---|---|
| `0x68bc` | `0x6646` | **`0x6548`** | **시즌모드 경기 준비** (`strb #2,[r4,#1]` = 모드 2) |
| `0x30efc` | `0x30d82` | `0x30be0` | 대전/통신 경기 준비 (`0x1f890`·`0x1f8a8` 에서 두 팀) |
| `0x3119c` | `0x310d2` | `0x30f20` | 같은 계열 (`0x1f8c0`) |
| `0x3a364` | `0x3a01a` | `0x39fdc` 의 **모드 0** 가지 | 경기 장면 초기화(모드별 점프표 `0xcfef8`) |
| `0x3a364` | `0x3a228` | `0x39fdc` 의 **모드 3·4** 가지 | **나만의리그 경기 준비** |
| `0x3a5d0` | `0x3a4c2`·`0x3a4d2` | `0x39fdc` 의 **모드 7** 가지 | 홈런더비 |
| `0xaa8f4` | `0xaa730` | — | 미션 계열 (`0x1f8d4`) |
| `0xc25b0`·`0xc2d94` | `0xc241e`·`0xc2cb4` | `0xc2c4c` 등 | CPU 끼리 간이 시뮬 (P5 1a 절) |

모드 **1·2·8·9** 는 `0x39fdc` 에서 **읽기만**(`0xb6bdd`) 한다 — 그 전에 이미 채워져 있다.
곧 **시즌모드(모드 2)의 유일한 채우는 자리는 `0x6548` 이다**.

### 1-1. 시즌모드 경기 준비 `0x6548` (장면 0x105, `this+0xa0` = SR, `L = SR+0x80`)

```
65a0: r4 = this+0xa0 ; r0 = SR ; r5 = 0x12c
65ac: r3 = SR[0x12c]            ; 국가대항전 진행 플래그 (= L+0xac)
65b2: r2 = SR + 0x80 = L
65b6: beq 0x65ec                ; 0 이면 정규/포스트시즌 가지

; ── 국가대항전 가지 ──
65b8: r6 = 0x12d ; r4 = 0xb7615
65bc: r1 = (s8) SR[0x12d]       ; = L+0xad, 남은 단계 n
65c6: bl 0xb7614(L, n, 0)       ; → [sp+0x18]
65da: bl 0xb7614(L, n, 1)       ; → [sp+0x14]
65e2: cmp r5,#0xa ; beq …       ; 칸 0 이 10(대한민국)이 아니면 둘을 맞바꿈
                                ; → [sp+0x18] = 내 팀(늘 10) · [sp+0x14] = 상대

; ── 정규/포스트시즌 가지 ──
65ec: r0 = (s8) SR[1]           ; 내 팀
65f4: [sp+0x18] = 내 팀
65fa: bl 0xb765c(L, 내팀)       ; 상대 → [sp+0x14]

; ── 공통 ──
6600: [sp+0x10] = 0xb7844(L, [sp+0x18])   ; 내 쪽 side
660e: r5        = 0xb7844(L, [sp+0x14])   ; 상대 쪽 side
661c: r4 = [0x1552d0c]          ; 경기 상태 st
6626: 0xb6814(st)               ; 경기 초기화
662c: strb #2, [r4, #1]         ; st[1] = 모드 2
6636: 0xb6c18(st, 내side,  0)   ; 내 쪽 = PLAYER
6640: 0xb6c18(st, 상대side, 1)  ; 상대 = COM
664c: 0xb6bd4(st, 내side,  [sp+0x18])   ; ★ 경기[0x28 + 내side]  = 내 팀 번호
6656: 0xb6bd4(st, 상대side, [sp+0x14])   ; ★ 경기[0x28 + 상대side] = 상대 팀 번호
```

`0x6644~0x6658` 그대로 인용 (베니어 `0xcaa04` 는 `r6` 으로 간다):
```
    6644: 1c20         	adds	r0, r4, #0x0
    6646: 4e9d         	ldr	r6, [pc, #0x274]        @ 0x68bc      ; [0x68bc] = 0xb6bd5
    6648: 9904         	ldr	r1, [sp, #0x10]                       ; 내 side
    664a: 9a06         	ldr	r2, [sp, #0x18]                       ; 내 팀 번호
    664c: f0c4 f9da    	bl	0xcaa04
    6650: 1c20         	adds	r0, r4, #0x0
    6652: 1c29         	adds	r1, r5, #0x0                          ; 상대 side
    6654: 9a05         	ldr	r2, [sp, #0x14]                       ; 상대 팀 번호
    6656: f0c4 f9d5    	bl	0xcaa04
```

나리(모드 3·4)도 같은 꼴이다 — `0x3a222`/`0x3a22e`, side 는 똑같이 `0xb7844`(`0x3a164`·`0x3a17a`).

## 2. `0xb7844(리그 L, 팀)` — side 를 정하는 유일한 자리 (확정)

```
b7846: r3 = L + 0xac ; r5 = 팀
b784e: cmp r3,#0 ; beq 0xb7868          ; 국가대항전이 아니면
; ── 국가대항전 ──
b7852: r1 = (s8) L[0xad]                ; 남은 단계 n
b785a: r2 = 0
b785c: bl 0xb7614                       ; 대진 칸 0
b7860: cmp r0,r5 ; beq 0xb78dc          ; 같으면 → movs r0,#1  (홈)
b7864: movs r0,#0                       ; 아니면 0 (원정)

b7868: r3 = L + 0x34 ; cmp #0 ; bne 0xb78e0   ; 포스트시즌?
; ── 포스트시즌 ──
b78e0: r3 = L + 0x35 ; r1 = (s8)[r3]    ; 라운드 r
b78e8: r2 = 1
b78ea: bl 0xb7648                       ; = (s8) L[0x38 + 2r + 1] = 대진 칸 1(아랫 시드)
b78ee: eors r0,r5 ; rsbs r3,r0,#0 ; orrs r3,r0 ; lsrs r0,r3,#0x1f
                                        ; → 아랫 시드면 0(원정), 아니면 1(홈)

; ── 정규시즌 (b7872~b78d4) ──
g   = (s8) L[0x32]
r7  = 0xca7b4(g, 9) & 1                 ; g/9 의 홀짝 — 9일 주기 한 바퀴마다 뒤집힘
if g > 0x16: r7 = !r7
row = (s8) 0xca910(g, 9)                ; g % 9
found = 0 ; for i in 0..팀-1: if 0xd89cb[row*10 + i] == (u8)팀: found = 1
return found ? r7 : !r7
```

- `0xb7648(L, r, k)` = `lsls r1,r1,#1 ; adds r1,r1,r0 ; adds r1,r1,r2 ; adds r1,#0x38 ; ldrsb`
  → **`(s8) L[0x38 + 2·r + k]`**. (P4 4b 의 "0xb7648(리그,r,1)/(리그,r,0)" 과 같은 함수다.)
- 정규시즌의 `for i in 0..팀-1` 루프는 일정표가 짝짓기(대합)라 **`상대(팀) < 팀` 인지를 보는 것과 같다**.
  웹 `leagueSideOf` 의 `team > opponentOf(day, team)` 와 정확히 같다 — 틀린 데 없다.

## 3. 포스트시즌 대진 칸 `L+0x38~0x43` (확정)

### 3-1. 깔기 `0xb80a8(L)` (정규시즌 45일째 뒤, `0xb818c` 가 부른다)
```
L[0x38] = 0xb802c(L,0,0)   ; 1위        L[0x39] = 10   ; 미정
L[0x3a] = 0xb802c(L,1,0)   ; 2위        L[0x3b] = 10   ; 미정
L[0x3c] = 0xb802c(L,2,0)   ; 3위        L[0x3d] = 0xb802c(L,3,0)  ; 4위
L[0x3e] = 4 ; L[0x3f] = 4                     ; 라운드 0 한국시리즈 = 4선승
L[0x40] = 3 ; L[0x41] = 3                     ; 라운드 1 플레이오프 = 3선승
L[0x42] = 3 ; L[0x43] = 3                     ; 라운드 2 준플레이오프 = 3선승
L[0x35] = 2   ; 라운드 (2 준PO → 1 PO → 0 KS)
L[0x32] = 0   ; 날짜
L[0x37] = 15  ; 우승팀 미정
```
→ **필요 승수 표는 `L[0x3e + 2·r + k]` 다** (라운드·쪽마다 따로 깎는다).

### 3-2. 한 판 끝 `0xb76dc` 의 포스트시즌 가지 `0xb7724`
```
r  = (s8) L[0x35]
r0 = (L[0x38 + 2r] == 승자) ? 0 : 1            ; 이긴 쪽 칸
L[0x3e + 2r + r0] -= 1
if L[0x3e + 2r + r0] != 0: return              ; 시리즈 계속
L[0x35] = r − 1 ; L[0x32] = −1
if r − 1 >= 0:  L[0x39 + 2(r−1)] = L[0x38 + 2r + r0]   ; 승자를 다음 라운드 **칸 1** 로
else:           L[0x37] = 승자 ; L[0x36] = 1            ; 우승·대회 끝
```
→ 올라온 팀은 **늘 아랫 시드(칸 1) = 원정**. 웹 `advancePostseason` 의 `teams: [topSeed, winner]` 와 같다.

**결론: 포스트시즌 홈/원정은 시드 고정이다.**
| 라운드 | 칸 0 = 홈(후공) | 칸 1 = 원정(선공) |
|---|---|---|
| 2 준플레이오프 | 3위 | 4위 |
| 1 플레이오프 | 2위 | 준PO 승자 |
| 0 한국시리즈 | 1위 | PO 승자 |

## 4. 국가대항전 홈/원정 (확정)

`0xb7614(L, n, k)`(P5 1a): `n>1` → `L[0xb8 + 4(4−n) + k]` · `n==1` → `L[0xae+k]` · `n<=0` → `L[0xc4]`.

- **풀리그**(`n` = 4·3·2): 칸 0 = `참가국[표 0xd89bc[4i+0]]` = `참가국[0]` = **대한민국(10)**.
  → 대한민국이 늘 **후공(홈)**, 상대가 선공.
- **결승**(`n` = 1): 칸 0 = `L[0xae]` = `0xb7f0c(L,0)` = 풀리그 **1위**.
  → 대한민국이 1위로 올라갔으면 후공, **2위로 올라갔으면 선공**.
- 대한민국이 결승에 못 들면 경기 자체가 없다(동전 던지기 `0xb858c`, P5).

## 5. 구장 그림 — 국가대항전은 **늘 일반 구장** (확정)

`0x40ff0`(배경 고르기)·`0x353a0`(경기 준비)의 조건은 **모드 2 이고 `0xb6bdc(경기,1) == SR[1]`** 이다(S3·R6).
`SR[1]` 은 **시즌모드 내 구단 번호**이고, 시즌모드에서는 히든 팀(10~14)을 고를 수 없다(J-1: 팀 고르기
`0x14114` 가 히든 칸을 **일반모드에서만** 열어 준다). 그런데 국가대항전의 `경기[0x28+side]` 에는
`0x6548` 이 **대표팀 번호 10~13** 을 넣는다 → 두 값은 절대 같아질 수 없다.

→ **국가대항전 경기에서는 후공이어도 `0x77494`(시즌 관중석·전광판) 를 안 탄다.**
포스트시즌은 모드 2 그대로라, **내 팀이 그 대진의 윗 시드일 때만** 내 구장이 나온다.
