## 요약
국가대항전은 **대한민국·일본·쿠바·미국 4국 풀리그 3경기(표 0xd89bc: 한-일/쿠-미, 한-쿠/일-미, 한-미/일-쿠) + 1·2위 결승 1경기**다.
대한민국은 늘 내 팀이고 매 라운드 사람 경기로 한 판, 같은 라운드 다른 경기는 0xc2dac 로 CPU 시뮬(판정 정상). 순위는 승 내림차순·패 오름차순, 동률이면 한·일·쿠·미 순.
대한민국이 2위 안에 못 들면 결승은 시뮬 없이 50:50(0xb858c). 매 경기 전 대한민국 투수 스태미나 전부 회복.
나리: 홀수 년차 연말에 올해 목표 4개 이상이면 선발(461) → 출전(463) 때만 치르고 거절(464)이면 S+0x12c=0 으로 바로 새 시즌.
시즌모드: 짝수 연차idx 마다 무조건 출전(상태 242~244), 명단 조작 없음.
대표팀 명단: 내 선수를 원래 팀 로스터 칸 k 에 끼우고 그 칸 대한민국 선수는 벤치 끝으로, 타자는 그 선수의 수비 위치를 물려받는다.
보상: 나리 우승 인기+20·평판+30·소지금+2000만·G+1000(준우승 없음) / 시즌 우승 +30·+40·+5000만·G+1000, 준우승(결승 패) +20·+20·+2500만.
**S+0x12c(= L+0xac)는 국가대항전 진행 플래그** — B 의 "국가대표 플래그"가 맞고 P1 의 "포스트시즌 플래그"는 잘못 읽은 것(같은 칸).
S+0x144 = 우승팀, S+0x12e/12f = 결승 두 팀 → J-1 히든 팀 조건 확정(대한민국 우승 시 결승 상대 오픈).
남은 것: 이벤트 끝 → 상태 101 연결은 유력(칸 쓰기는 확정), 시즌모드에서 S+0x12c 를 0 으로 되돌리는 곳, 선수 +0xa 의 0x40/0x20 표시 뜻, 대회 뒤 대표팀 명단 정리 여부, 순위표 0x7f070 의 4줄 내용.

> **홈/원정**: 국가대항전 경기의 선공·후공은 `0xb7844` 가 `0xb7614(L, L+0xad, 0)`(대진 칸 0)로 정한다 —
> 풀리그는 칸 0 이 늘 대한민국이라 **대한민국이 후공(홈)**, 결승은 칸 0 = `L+0xae` = 풀리그 1위라
> 대한민국이 2위면 **선공**이다. 구장 그림은 `경기[0x29]` 가 대표팀 번호(10~13)라 `SR[1]`(내 구단 0~9)과
> 절대 같지 않아 **늘 일반 구장**이다. 자세히는 **S11**.

## 1a. 상태 134 = 0x19f30 (진행 중 메모)
```
19f3a: bl 0x85af1([this+0xe0])        ; 빈 함수(bx lr)
19f46: 0x65de5([0x1552cfc], 0)         ; 대한민국 오픈
S = [this+0xb0]
if s8 S+0x144 == 10: r1 = s8 S+0x12e; if r1 == 10: r1 = s8 S+0x12f; 0x65de5(g, r1-10)
if s8 S+0xb2 == 0: t = 0x1f9a9([0x1400054],[0x1552d10],10); 0xb6191(t)   ; 팀10 투수 스태미나 회복(P1: 0xb6190=전원 10000)
```
→ 경기 자체는 이 함수에 없다. 경기는 다른 상태/장면에서 돈 뒤 결과가 S+0x144/0x12e/0x12f 에 남아 있어야 한다.

### 상태 133 0x1a090 재확인 (S = [this+0xb0], 리그 L = S+0x80)
- S+0x12c(= L+0xac) = 0 → 0xa3de8(S,3) > 3 이면 1. (B 의 "career" = 이 S. P1 의 S+0x12c 와 **같은 칸**.)
- 선발: 이벤트 461(0x8bdc9(this+0x160, 0x1cd)) · next 134 · **0xb7bf1(L) = 국가대항전 리그 초기화** · T=0x1f9a9(g,모드,10) ·
  모드4(타자) → 0xb53f1(T, 0x1fc21(g), 1) ; 0x1faa1(g,0,1) / 그밖(투수) → 0xb521d(T, 0x1fbd1(g), 1) ; 0x1faa1(g,1,1) · 0x1fded(g) · 0x22755(g,1)
- 탈락: 이벤트 462 · next 105. 두 경우 다 마지막에 next 114.
- 0xbcb48(q, st) = `q+0xc = q+8 ; q+8 = st ; q+0x18 = 1` — 줄이 아니라 "다음 상태" 한 칸 + "돌아갈 상태" 한 칸. 나중 호출(114)이 next, 앞 호출(134)이 +0xc 로 밀린다.

### 국가대항전 리그 초기화 0xb7bf0(L) — 확정
```
L+0xae = L+0xaf = 15            ; 결승 두 팀 (미정 15)
L+0xa8..ab = 10,11,12,13        ; 참가 4국: 대한민국·일본·쿠바·미국
memset(L+0xb0,0,4); memset(L+0xb4,0,4)   ; 4국 승/패(유력)
L+0xad = 4 ; L+0xc4 = 15 (우승팀 미정) ; L+0x32 = 0 (날짜 g)
for 라운드 i 0..2, 칸 j 0..3: L+0xb8+4i+j = L+0xa8[ 표 0xd89bc[4i+j] ]
0x205c1(g,모드) ; 0xb6191(0x1f9a9(g,모드,10)) ; 0x20649(g,모드, 0xb7614(L, 4, 1))
```
표 0xd89bc = [0,1,2,3, 0,2,1,3, 0,3,1,2] → 풀리그 3라운드 × 2경기:
- 1R 한국-일본, 쿠바-미국 · 2R 한국-쿠바, 일본-미국 · 3R 한국-미국, 일본-쿠바

### 하루 끝 0xb818c(L) 의 국가대항전 가지 — 확정
```
L+0x32 (g) += 1
if L+0xac (국가대항전 중):
    L+0xad -= 1                                   ; 남은 단계 4→3→2→1→0
    if L+0xad == 1: L+0xae = 0xb7f0c(L,0) ; L+0xaf = 0xb7f0c(L,1)   ; 결승 두 팀 = 순위 1·2위
    0xb6191(0x1f9a9(g,모드,10))                   ; 대한민국 투수 스태미나 전부 회복
    opp = 0xb7614(L, L+0xad, 1); if opp == 10: opp = 0xb7614(L, L+0xad, 0)
    0x20649(g, 모드, opp)                          ; 다음 상대 등록
```
- 0xb7614(L, n, k): n>1 → L+0xb8 + 4·(4−n) + k (라운드 4−n 의 첫 경기 k번째 팀) · n==1 → L+0xae+k (결승) · n≤0 → L+0xc4 (우승).
  → 대한민국은 늘 라운드 첫 경기(칸 0)라 k=1 이 상대.
- 0xb7f0c(L, k): 4국 [L+0xa8..ab] 를 승 L+0xb0..b3 내림차순, 같으면 패 L+0xb4..b7 오름차순으로 교환정렬(i<j, 같으면 원래 순서 = 한·일·쿠·미 우선) 후 k 번째.
- **대회 = 4국 풀리그 3경기 + 1·2위 결승 1경기**. 우승팀 L+0xc4.
- 승·패 기록 0xb76dc/0xb77e0(L, 팀): L+0xac 이면 팀의 참가국 순번 i(L+0xa8..ab 검색) → 승 L+0xb0+i ++ / 패 L+0xb4+i ++.
  **승 기록 때 L+0xad == 1(결승 날)이면 L+0xc4 = 이긴 팀** (우승팀). 정규 기록(연승·상대전적 등)은 건드리지 않음. — 확정

### CPU 끼리 국가대항전 경기 — 확정
- 사람 경기 결과 장면 0x4ea0c, 0x4f216~0x4f266: `L = scene+0xf0c`; L+0xac 이고 **L+0xad > 1(풀리그 날)** 이면
  `a = 0xb7614(L,n,2) ; b = 0xb7614(L,n,3) ; 0xc2dad(scene+0x1780 sim, …, L, a, b)` → 같은 라운드 둘째 경기를 CPU 로 한 판 돌림. 결승 날(n==1)엔 없음.
  이어서 0x4f29a `0xb818d(L)` 하루 끝.
- 0xc2dac(sim, 모드?, L, a, [sp+0x100]=b): 준비 0xc2c4c 가 a 를 칸 1(0xb6bd5(st,1,a)), b 를 칸 0 에 넣음. 선발은 양 팀 `L+0x32 % 4` 번째 투수(0xb6c2d).
  간이 타석 루프(0xc262c)를 0xc2198 끝날 때까지 → `score(칸1) > score(칸0) ? (a 승, b 패) : (b 승, a 패)` (c2f12~c2f46). **정상 판정**(R1 의 0xc2a48 뒤집힘 버그 없음). 동점이면 b 승.

### 국가대항전 순위 화면 키 처리 0x19fdc — 확정
(this+0x40 키 == −5 또는 0x35 일 때만. UI = [this+0xe0], 그리기 0x85af4 가 S+0x12d 를 읽음)
```
if L+0xad == 1 (결승 날) and 0xb8565(L) == 0 (대한민국이 결승 두 팀 L+0xae/af 에 없음):
    0xb858d(L): L+0xc4 = rand(0,2)==0 ? L+0xaf : L+0xae      ; 결승을 치르지 않고 50:50 으로 우승 결정
    0x85e6d(UI, 0)                                           ; 결과 화면(대한민국 우승 아님)
elif L+0xad == 0 (대회 끝):
    0x85e6d(UI, L+0xc4 == 10)                                ; 결과 화면, 1 = 대한민국 우승
else:
    next 0x87 = 상태 135                                     ; 다음 경기로
0xbbef9(0x1552af4,1,0x25,1)  (결과 화면 가지에서만; 효과음 유력)
```
→ **대한민국이 풀리그 2위 안에 못 들면 결승은 시뮬 없이 동전 던지기**. 결승에 들면 사람 경기로 결승을 치르고 승 기록 때 L+0xc4 가 정해짐.

### 상태 흐름 (나만의리그) — 확정
- 들어올 때 처리 0x1cdec: 표 0xcc728[상태−100] · 키 처리 표 0xcc7e0[상태−102].
- 133 들어옴 0x1a090 → (461 이벤트, next 114 / 돌아갈 134)
- 134 들어옴 0x19f30 (히든 팀 열기·첫날 회복) · 키 0x19fdc (위) → 경기 남음이면 **135**
- 135 들어옴: 없음 · 키 0x10680: 확인(−5/0x35) → **142**
- 142 들어옴 0x1c46c = 사람 경기 준비(P1 1-1). S+0x12c 면 `내 팀 = 0xb7614(L,n,0), 상대 = 0xb7614(L,n,1)`; 내 팀 ≠ 10 이면 둘을 맞바꿈 (1c496~1c4da).
  (0x19fdc 가 대한민국이 결승에 없을 때 경기를 막으므로 사람 경기는 늘 대한민국 경기.)
- 경기 뒤 나리 장면 재진입 = 상태 101 들어옴 0x1c154: S+0x50(돌아온 이유)로 분기(6·7→141, 0x11→새 시즌, 2, 0xb, 9, 0xc·0xd→130/131, 0xe, 0xa→연말 판정…).

### 결과 화면 0x85e6c(UI, 우승?) — 확정
- n = (S+0xb3 연차idx >> 1) + 1 = **제 n 회** (1·3·5…년차 → 1,2,3…회)
- 우승(인자 1): sprintf(StrMODE[144] "[대한민국] 대표팀 제%d회 국가대항전 우승!!", n)

### 나만의리그 보상 0x1b92c (팝업 닫힘 처리) — 확정

## 1b. 시즌모드 쪽 흐름 — 확정
- 상태 번호: 들어옴 표 0xcbea0[상태−200](0xe9ac), 키 표 0xcbf6c[상태−200].
- 시즌 끝 한국시리즈 결과 팝업 처리 0x85ec: 팝업 7 닫힘 → 0xb7aa1(L, 내 팀, 0) 가 0 → StrMODE[197](우승) 팝업 9 / 1 → [198](준우승) 팝업 0xa / 그 밖 → 바로 아래 판정.

## 2. 대표팀 명단 만들기 — 확정(동작) / 플래그 0x40·0x20 뜻 미해결
0x1a090 (나리 선발 때만. 시즌모드는 명단을 안 건드림):
`T = 0x1f9a9(g, 모드, 10)` = 대한민국 팀 레코드(모드별 저장). 선수 레코드 0x30 바이트, **+0xa: bit7 = 내 선수, bit6/5 = 다른 표시(미해결), 하위 5비트 = 로스터 칸 번호**.
보조: 0xb6720(P, 마스크, &k) = `P+0xa & 마스크` 면 k = P+0xa & 0x1f, 참 · 0xb4e34(T, 타자0/투수1) = 해당 배열 1칸 늘림 · 0xb51fc/0xb53d0 = 투수/타자 칸 포인터 ·
0xb6604(P, i) = +0xa 하위 5비트 = i · 0xb8e84(P, pos, 0) = P+0x1c = pos(수비 위치).
- **투수 0xb521c(T, 내 투수 0x1fbd1(g), 1)** (배열 T+0x14, 수 T+0xc):
  - P+0xa & 0x60 이면: T 투수가 9명 넘고 8번 칸도 0x60 표시면 8번 칸을 **덮어씀**(늘리지 않음), 아니면 1칸 늘려 8번 칸 선수를 맨 끝으로 옮기고 8번에 P.
  - 그 밖(내 선수 bit7 등): k = P+0xa & 0x1f → 1칸 늘려 **k번 칸의 대한민국 선수를 맨 끝(벤치)으로 옮기고 k번에 내 투수 복사**.
  - 마지막에 0x1faa1(g, 1, 1).
- **타자 0xb53f0(T, 내 타자 0x1fc21(g), 1)** (배열 T+0x18, 수 T+0x10):
  - P+0xa & 0x40 이면: 9번(첫 벤치) 칸 기준으로 위와 같은 덮어쓰기/끼워넣기.
  - bit7(내 선수) 이면: k = P+0xa & 0x1f; 1칸 늘림; 옛 k번 선수의 수비위치 pos = old+0x1c & 0xf 를 기억 → 옛 선수 위치 0 · 칸 번호 = 마지막 → 맨 끝으로 이동 → k번에 내 타자 복사 → **내 타자 수비위치 = pos**.
    = 내 타자는 원래 팀에서의 타순 칸 k 에 들어가고, 밀려난 대한민국 선수의 수비 위치를 물려받는다.
  - 0x20 표시 가지(b5532~)도 같은 모양.
- **0x1faa1(g, 투수?, 1) = "내 선수 포인터 다시 찾기"**: 경력 객체 +0x12c 가 켜져 있으면 팀 10(대한민국)에서, 아니면 원래 팀에서 내 선수를 찾아 g+0x38 에 둔다 (1faa0~1fb04).
  대회가 끝나면 S+0x12c = 0 뒤 다시 불러 원래 팀으로 돌아간다(0x1b9ea·0x1bae6). 대표팀 명단(팀 10 레코드)에서 내 선수를 빼는 코드는 못 봄 → 다음 대회 때 다시 넣으면 칸이 또 늘어나는지 **미확인**.
- 대한민국 팀 투수 스태미나: 선발 시(0xb7bf0 끝)·하루 끝(0xb818c)·첫날(0x19f30) 모두 0xb6190 = 전원 10000 → **국가대항전은 매 경기 완전 회복**.

## 0x12c 충돌 정리 — 확정
- B 의 "career+0x12c" 와 P1 의 "S+0x12c" 는 **같은 칸**(나리 장면 +0xb0 객체 = 경력/시즌 객체 S, 리그 L = S+0x80 → S+0x12c = L+0xac).
- 뜻은 **국가대항전 진행 중 플래그**. 포스트시즌 플래그가 아니다(포스트시즌은 L+0x34, R1 참고).
  근거: 0x1a090 이 선발 때 1 로, 0x1b9ea/0x1ba42 이 대회 끝에 0 으로(나리), 0x1b768 새 시즌에 0; 0xb76dc/0xb77e0/0xb818c 는 L+0xac 이면 국가대항전 4국 승패·결승 처리; 0x1faa1 은 이 플래그면 팀 10(대한민국)에서 내 선수를 찾음.
- 따라서 P1 1-2 의 "포스트시즌이면 −2" = **국가대항전 중엔 선발 로테이션 교환 없음**, "포스트시즌 팀은 팀 번호 10" = 대한민국, 0xb818c "포스트시즌 경기 전 내 팀 완전 회복" = 대한민국 투수 전원 회복으로 고쳐 읽어야 한다. 0x4ea0c 가 L+0xac 로 고르는 CPU 경기도 국가대항전 같은 라운드 둘째 경기.

## 4. S+0x144 / +0x12e / +0x12f (J 의 "리그+0x144" 는 실제로 S 기준, = L+0xc4 / L+0xae / L+0xaf) — 확정
쓰는 곳 (all.dis 전수: league 코드 0xb7000~0xb9fff 의 +0xc4/+0xae/+0xaf 저장, S 기준 0xa2<<1 저장):
| 칸 | 쓰는 곳 | 값 |
|---|---|---|
| L+0xae / L+0xaf (S+0x12e/12f) | 0xb7bf0 초기화 | 15 (미정) |
| | 0xb818c 하루 끝, 남은 단계가 1 이 될 때 | 0xb7f0c(L,0) / (L,1) = 풀리그 1위 / 2위 |
| L+0xc4 (S+0x144) | 0xb7bf0 | 15 |
| | 0xb76dc 승 기록, L+0xad == 1(결승 날) | 결승 이긴 팀 |
| | 0xb858c (대한민국 결승 탈락 때) | rand(0,2)==0 ? L+0xaf : L+0xae |
- 다른 0xa2<<1 저장(0x10ef4, 0x8d7cc)은 전역 저장 객체(0x1f1d9) 쪽이라 무관.
- **J-1 확정**: 히든 팀 일본·쿠바·미국 = 대한민국이 결승에서 이긴 상대. 0x19f30/0xe684 가 `S+0x144 == 10` 이면 `S+0x12e`(10 이면 `S+0x12f`) − 10 을 연다.
  대한민국이 결승에 못 가면 L+0xc4 ≠ 10 이라 결승 상대 팀은 안 열림. 대한민국(k=0)은 상태 134/243 에 들어가기만 하면(=출전하면) 열림.
- 주의: 134/243 은 라운드마다 다시 들어오므로 대한민국 열기는 매번 불리지만 0x65de4 가 이미 열려 있으면 아무것도 안 함.

## 5. 상태 114 / 128 연결 — 114 확정, 이벤트 끝 → 1 은 유력
- 상태 기계 도우미: 0xbcb48(q, st) 는 `q+0xc(=this+0x24) = q+8 ; q+8 = st` — 먼저 넣은 상태가 "돌아갈 상태"(this+0x24)로 밀린다. 0xbc9c8 이 매 프레임 `cur(this+0x1c) != next` 면 prev=cur, cur=next, 들어옴 처리.
- **114 = 0x11d00 이벤트 표시 상태**: 이벤트 UI([this+0xe0]) 연결, 0x8be21(this+0x160) 이벤트 시작, 배경음(0x6ea6d, 0x28). 키 0x13b88 = 키를 이벤트 객체 0x8b805 로 넘김.
  이벤트가 끝나면 상태 1 → 0x13f08(갱신 표 0x1d25a) 이 `this+0x24`(돌아갈 상태)로 보냄(140bc: `ldr r1,[r2,#0x24] ; 0xbcb49`) (단 돌아갈 상태가 105·101·141 이면 다른 처리).
  → 0x1a090: 선발이면 [461 이벤트(114) → 134 순위 화면], 탈락이면 [462 이벤트(114) → 105].
  (단 461 은 이벤트 끝 처리 0x8c460 이 S+0x50 을 3(출전)/0x11(거절)로 바꾸므로, 실제로는 재진입 0x1c154 가 S+0x50 으로 134 / 새 시즌을 고르는 것으로 보인다 — 아래 "461 선택 결과". 이벤트 끝이 상태 1(0x13f08)인지 101 인지는 유력.)
- **128 = 0x120a4 시즌 끝 순위 화면**(S+0x50 = 0xf, 저장, 순위표 0x8533d, 정규 1위면 StrMODE[191] 팝업 0xb; 키 0x13da0 이 0xc2760 한 경기 시뮬을 부름 = 포스트시즌 쪽). 국가대항전과 직접 연결은 없다. 순서는 B 대로 131(MVP) → 128 → 132(연말) → 133(국가대표) → 134….
- 국가대항전 한 바퀴 (나리):
  `133 → 114(461) → 134[순위] → 키 → 135 → 키 → 142[경기 준비 0x1c46c] → 사람 경기 → 결과 장면 0x4ea0c(같은 라운드 CPU 경기 0xc2dac, 하루 끝 0xb818c)`
  `→ 101(재진입 0x1c154, S+0x12c 면) → 134 … (4번) → 대회 끝이면 134 키에서 결과 팝업 0x25 → 0x1b92c: 우승이면 보상 팝업 0x26 → 새 시즌 0x1b768`
- 시즌모드: `0x85ec(한국시리즈 결과) → 242 → 211(461) → 243[순위] → 244 → 221(경기) → 0x4b50 재진입 → 243 … → 결과 팝업 1 → 0x896c 보상 → 0x6e0c`.
