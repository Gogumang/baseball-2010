# F. 화면 배치 좌표 (코드 안에만 있는 것)

## 요약
**풀린 것 (확정)**
1. **알림·질문 창**: 버튼은 글자가 아니다. ui/popup.pzx 프레임 그림이다. 알림은 프레임 0 "OK". 예/아니오는 비선택 1·2(파랑), 선택 6·7(주황)이다.
   - 크기: 높이 = 줄수×14+50+버튼15, 버튼 아래 여백 15, 가로 간격 40. 글은 흰색이다.
   - 열 때 높이가 10에서 시작해 매 틱 두 배로 세로로 펼쳐진다. 닫을 때는 폭이 매 틱 반으로 줄어든다.
2. **외출 지도** (포크):
   - 지도는 (0,11)에 놓이고, 건물 좌표는 각 프레임 원점이다.
   - 밤에만 화면을 어둡게 하고 프레임 6(창문 불빛)을 그린다.
   - 장소 이름은 1px 외곽선 글자다.
   - 화살표와 [!] 기준점은 웹과 다르다.
   - 말풍선은 박스3에 두 칸이다: [들어가기]=StrMODE[48], 기능=StrMODE[49+i].
3. **HUD**:
   - 0x4c4bc는 커서가 아니라 타석 화면 전체를 그리는 함수다. 원본에는 커서가 없다.
   - 점수는 ui/num.pzx 숫자를 오른쪽 정렬로 그린다.
   - 새 램프는 5배에서 1배로 5틱 동안 줄어드는 확대 연출이 있다(웹은 "없음"으로 적어 둠).
4. **타이틀**:
   - main_title 애니 0(인트로 20틱)이 끝나면 애니 1이 반복된다: **PRESS ANY KEY**, 끔2·흐림1·켬4·흐림1.
   - 선수 안착은 6틱째다.
   - 저작권 프레임 18은 (59,308)에, num "2"는 (189,308)에, 전체이용가는 (198,2)에 그린다.
   **메인 메뉴**:
   - (120,320)을 중심으로 한 반원 바퀴다. 반지름 93/95/97 원 3겹을 그린다.
   - 6칸 각도는 [0,45,90,180,270,315]이다. 한 칸 이동은 5틱이다.
   - 칸 그림은 img_text 전역 스프라이트에서 가져온다.
5. **훈련 팝업** (포크):
   - 세로 보정 d는 인자다. 관리 화면에서는 0이고, 가운데 판에서는 59다.
   - 캐릭터 그리기: 모드 4는 겹침 타자(0x78cfd), 그 밖은 0x79525(프레임 번호를 그대로 씀)다.
   - 장타형 동작표 0xd4a18·0xd4a6c가 따로 있다.
6. 웹 전용 화면:
   - **경기 결과**를 풀었다: y40 반투명 띠, game_ui 프레임 8, YOU WIN/LOSE를 (120,50)에, 패배면 화면을 어둡게 한다.
   - **공용 창 0x55e60**을 풀었다: #335FCD 판, #080408 테두리.
   - **공용 페이지 0x593c8**을 풀었다: 종류 8이 환경설정이고, 가운데 192 폭 창이다.
   - 공용 UI 스프라이트 [0x1552aec]는 **ui/img_text.pzx**다.
   - 메인 메뉴 하위 상태 16~42의 그리기 함수 목록을 뽑았다.
7. **속도 기본값 = 2번(16fps, 62ms)**: 옵션 생성자 0x9f2a4에서 확인했다. 웹 값과 같다.

**남은 것**
- 미션 선택·기록·스페셜·시즌 끝·상점: 그리기 함수의 화면 이름을 맞추는 일과 줄별 좌표는 미해결이다(6-4~6-6에 후보를 적었다).
- 메인 메뉴 칸별 그림 분기의 뜻, 효과 1/7·0x10의 정확한 뜻, 외출 이름 박스의 mapY 누락이 실기에서 어떻게 보였는지도 남았다.

## 1. 알림·질문 창 (0xbbef8 → 0x74ef4 배치 · 0x746cc 그리기 · 0x744c4 판 · 0x74664 글 · 0x74824 버튼 배치)

### 1-1. 상자 모양 (확정, 앞선 layout-re 4차와 같음)
- 0x744c4: 판 RGB(51,95,205)=#335FCD 을 fillRect, 위·아래 5줄 선 색 배열
  `(30,26,166) (30,26,166) (255,255,255) (123,158,255) (123,158,255)` = #1E1AA6 ×2 · #FFFFFF · #7B9EFF ×2 (0x7458a~0x745c0).
- 상자 x = (scrW − w)/2, y = (scrH − h)/2 + [+0x244] (0x744ea~0x7451c). w = scrW (0x7502a 에서 [+0x210] = scrW).
- 뒤 어둡게: 0x74546 `0xbae25(0, x, y, …)` — [+0x24e] 켜짐일 때만 (뜻: 배경 어둡게, 호출 인자 이상은 미확인).
- 글: 0x74664 → `0xba269(글, scrW/2 − 75, 상자y + 20 + [+0x244], 폭 150, RGB(255,255,255), 0)` — **흰 글씨**, 폭 150.
- 높이: 0x74ffe `h = 줄수×14 + 50` 저장 후 0x74824 가 버튼 줄 높이를 더한다.

### 1-2. 버튼 = ui/popup.pzx 프레임 그림 (확정 — 새로 풀림)
- 0x74a64 가 `ui/popup.pzx`(문자열 VA 0xd367c) 를 적재, 상자 객체 [+4] 에 둔다.
- 0x750c0: 종류 = `[상자+8] & 0x1f`, 점프표 0xd368c(u32×16):
  종류1→0x75178, 종류2→0x750d6, 종류3→0x750dc, 종류4→0x75234, 종류8→0x75394(추정 경로), 종류16→0x753f4, 나머지 끝.
- 버튼 생성 0x74ea8(상자, 그림A, 그림B, 첫버튼?) → 0x74adc: 버튼 객체 +0x18=그림A, +0x1c=그림B, 폭·높이는 그림B 의 +0x12/+0x14.
  그림은 `[[상자+4]+0xc]+8` = **popup 프레임 배열**.
  - 종류 1 (알림): 0x75178~0x751b8 — 프레임 **0 "OK"**(파랑) 하나, 선택/비선택 모두 0.
  - 종류 2·3 (예/아니오): 0x750f8~0x75140 — 버튼1 = (프레임 **6** 주황 "예", 프레임 **1** 파랑 "예", 첫버튼=1),
    버튼2 = (프레임 **7** 주황 "아니오", 프레임 **2** 파랑 "아니오", 0).
  - 즉 **선택 색 = 주황 그림(6/7), 비선택 = 파랑 그림(1/2)**. 글자 "확인/예/아니오" 문자열은 없다 — 그림 속 글자다.
  - popup 프레임 3 "새로하기", 5 "빠른실행" 등도 있다(종류 4/16 쪽, 미확인).
- 버튼 배치 0x74824: 버튼들의 최대 폭·높이를 구해 가로 간격 [+0x264]=**40**, 세로 간격 [+0x268]=**10** (0x750a8·0x750b6),
  시작 x = scrW/2 − (열수×폭 + (열수−1)×40)/2 (0x748e0~0x748fe). 세로 위치는 상자 아래쪽 기준(식 일부 미확인).

### 1-3. 크기·버튼 위치 식 (확정)
- 생성자 0x75700~0x757c6: [+0x264]=40(가로 간격), [+0x268]=10(세로 간격), [+0x26c]=**15(버튼 아래 여백)**.
- 0x74824 (버튼 배치): 격자 객체 [+0x218] 의 열수·행수 (종류 1 = 1×1, 종류 2 = 2열×1행: 0x750f4 `vtbl+0x10(obj, 2, 1, 1, 816, 0)`).
  - 목표 높이 `h = 줄수×14 + 50 + 행수×버튼높이 + (행수−1)×10` (0x7488a~0x748b2).
  - 상자 y = (scrH − h) >> 1 (0x748c6~0x748d2), 상자 x = 0, 폭 240.
  - 버튼 첫 x = scrW/2 − (열수×최대폭 + (열수−1)×40)/2, 열마다 +(폭+40) (0x748e0~0x7493c).
  - 버튼 첫 y = 상자y + h − 15 − (행수×높이 + (행수−1)×10) (0x74900~0x74922).
  - 버튼 크기는 비선택 그림(파랑) 프레임의 +0x12/+0x14 — popup 프레임 0·1·2 는 41×15.
  - **계산 예 (한 줄, 예/아니오)**: h = 14+50+15 = **79**, 상자 y = 120, 글 y = 140, 버튼 (59,169)·(140,169), 버튼 아래 여백 15.
    선택 그림 6·7 은 49×23 이라 같은 기준점에 4px 씩 넘쳐 그려진다(프레임 원점은 PZX 에 있음 — PNG 잘림 기준 아님, 원점값은 미확인).
- 버튼 그리기 0x74d14: `[btn+0x14]`(선택)=0 → 그림B(+0x1c, 파랑), ≠0 → 그림A(+0x18, 주황). 처음 선택은 첫 버튼(0x7511a 인자 1).

### 1-4. 열림·닫힘 애니메이션 (확정 — 새로 풀림)
- 열 때 0x75006: 그리는 높이 [+0x212] = **10** 에서 시작, 열림 플래그 [+0x214]=1 (0x74f96).
- 갱신 0x75556~0x75588: 매 갱신 **높이 ×2** (10→20→40→80…), 2배가 목표 h 이상이면 h 로 맞추고 플래그를 끈다.
  상자는 늘 (scrH − 현재높이)/2 에 그려져 **세로 가운데에서 위아래로 펼쳐진다** (0x74502~0x74520). 한 줄(79)이면 10→20→40→79, 3번 갱신.
- 펼쳐지는 동안(플래그 켜짐)은 글·버튼을 그리지 않는다 (0x7479c~0x747a6 `bne` 끝).
- 닫을 때 [+0x215] 켜짐: 매 갱신 폭 [+0x210] **÷2** (240→120→60), 99 이하가 되면 닫고 콜백 (0x7558a~0x755d8).
- 뒤 어둡게 (0x74704~0x7474a): [+0x24d] 가 켜진 첫 그리기에서 한 번만 화면 전체(0,0,W,H)에 RGB(0,0,0) 을 함수포인터 [0x15605d0] 로 **단계 5** 로 섞는다 (뜻: 반투명 단계, 정확한 불투명도는 미확인).

### 웹판과 다른 점
- `src/shared/ui/MessageBox/MessageBox.css.ts:9-14` — 한 줄 상자를 86 높이(글→버튼 22, 버튼 12, 아래 18)로 둔다. 원본은 79(글 뒤 15 띄고 버튼 15, 아래 15).

  원본은 popup 프레임 그림(0 OK / 1·6 예 / 2·7 아니오), 선택은 주황 그림으로 바꾼다. "확인" 이 아니라 "OK" 다.
- 글 색: 웹은 `ORIGINAL_COLORS.text`, 원본은 흰색 (0x74682).

## 7. 속도 옵션 기본값 — **확정: 2번(16fps, 62ms)**
- 옵션 구조체는 `game_o.sav`(문자열 0xcdb68) 로 저장되는 0xe44 바이트 객체([게임+0xac]). 파일이 없으면 0x20138 → 0x202d4 에서 생성자 0x9f26d 를 불러 기본값을 넣고 저장한다.
- 0x9f26c 생성자:
  ```
  0x9f27c  adds r3,r7,#0 ; movs r2,#2 ; adds r3,#0x2c ; strb r2,[r3]   ; [+0x2c] = 2
  0x9f284  adds r3,#2 ; strb r2,[r3]                                    ; [+0x2e] = 2 (소리 크기, 곧바로 0x6e4d1(…, 0x32=2×25) 로 적용)
  0x9f29c  adds r3,#0x3b ; movs r5,#2 ; strb r2(1),[r3]                ; [+0x3b] = 1
  0x9f2a2  subs r3,#0xc ; strb r5,[r3]                                  ; [+0x2f] = 2  ← 속도
  0x9f2a6  subs r3,#2 ; strb r4(0),[r3]                                 ; [+0x2d] = 0
  ```
- 적용 0x9f524: `fps = 표0xd7624[(s8)[옵션+0x2f]]`, 표 = u32 [4, 10, 16, 22, 28] → 0xbc179 가 `1000 / fps` 를 한 틱 ms 로 둔다 (0xbc180 `movs r0,#0xfa; lsls #2` = 1000, 0xca7b5 = 나눗셈). 기본 1000/16 = **62ms**.
- 환경설정 좌우 키(0x29644)는 이 바이트를 ±1 한다.
- 웹판: `src/shared/config/frameRate.ts:6,14` `DEFAULT_SPEED_LEVEL = 2` — 값은 원본과 같다. 주석의 "추정"만 "확정(0x9f2a4)"으로 바꾸면 된다.

- [this+0x138] 가 어느 파일인지(mode_ui 로 보임), 박스 값, 칸 내용은 미해결. 웹 `src/pages/shop`·`src/widgets/item-window` 과의 대조도 못 했다.

### 6-5. 못 한 화면 (미해결)
- 미션 선택·기록(성적)·스페셜·시즌 끝: 이번 세션에서 그리기 함수를 찾지 못했다. 시도한 길: 메인 메뉴 상태표(0xcf164/0xcefa4)에서 상태 16~38 의 그리기 함수 목록까지는 뽑았다(4-0 표) —
  이 중 0x2dxxx 묶음(상태 16~36)이 스페셜·기록·랭킹 같은 메뉴 하위 화면일 가능성이 높다. 다음 단계: 각 함수의 0x702b5 문자열 번호로 화면 이름을 맞추기.
