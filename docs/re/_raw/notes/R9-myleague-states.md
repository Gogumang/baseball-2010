## 요약
나만의리그 장면 0x106 의 상태 46칸(100~145, +표 밖 1)을 모두 풀었다. 상태 기계는 0x1cdec 한 틀 안에서
진입 표 0xcc728[s−100] · 키 표 0xcc7e0[s−102] · 그리기 표 0xcc884[s−101] 세 점프표와, 표가 아닌
"틀 처리" 비교 나무 0x1d1b2 로 돈다(2절). 상태 객체는 장면+0x18 에 인라인으로 놓여 **다음(+8)·뒤(+0xc)**
두 칸을 쓰므로, `0xbcb49(X); 0xbcb49(114)` 한 쌍이 "이벤트를 보고 나서 X 로" 를 뜻한다 — 이 한 수로
114(이벤트 재생)가 어느 상태에서나 끼어들고 제자리로 돌아온다(2a).

새로 푼 것: 100 재진입 분기(2b, S+0x50 표), 1 자원 적재, 105 관리 커맨드 표 0xcc540, 106 선수정보 표
0xcc69c, 109 순위표, 110·111 상점, 112·113·126 외출, 115 연초 처리(= 시즌 0xd4 와 공유하는 0x8a680 —
StrUSER_EVT[1] 내장 이벤트 두 줄 + 올해의 목표 창, 마이너스 스킬 해제 플래그 0xa4ee8 초기화),
116 경기 뒤 평가(관리 화면이 두 경기에 한 번인 근거), 117 중간 성적표, **118 은 쓰지 않는 빈 칸**,
119·120·129 기본정보 곁가지, 124·127·128(포스트시즌 보상 적용처) , 137 새 시즌 "N년차" 표지,
139 G 충전, 141·145 엔딩·명예의 전당, 142·143·144 경기 앞 세 화면. 130~136·133~135 는 B·P5 문서를 가리킨다.

남은 것: 0x1b768(새 시즌 처리) 내부는 이 노트에서 요점만 스쳤다(137 로 넘기는 +0x289 플래그까지만).

## 2. 상태 기계 0x1cdec 의 네 칸 — 확정
한 틀에 차례로 (0x1cdec, r5 = 장면, r7 = 장면+0x18 상태 객체, 상태 = [장면+0x1c]):
1. **진입**: 0xbc9c9(상태 객체) 가 "상태 바뀜" 이면 `표 0xcc728[상태−100]` (0x1ce34~0x1ce44, 범위 0..0x2d).
2. **이벤트 자동 발동** 0x1cf9c: 상태 105(0x69) 또는 112(0x70) 일 때만 (A 3절).
3. **키 처리**: 팝업이 없고(0x754f9(0x140005c, [장면+0x40]) == 0) 키 플래그 byte[장면+0x34] ≠ 0 이면 `표 0xcc7e0[상태−102]` (0x1d06a~0x1d09a, 범위 0..0x28).
4. **틀 처리** 0x1d1b2: 상태 값 비교 나무(표 아님) — 팝업 닫힘 결과 처리·애니 등. 끝에 공통 0x16a34.
5. **그리기**: `표 0xcc884[상태−101]` (0x1d336~0x1d346, 범위 0..0x2c).
(C 문서가 "0x1d1b2 = 그리기" 라 적은 것은 4번 틀 처리 나무다. 그리기는 5번.)
상태 바꿈은 `0xbcb49(장면+0x18, s)` = 다음 틀 예약 (P4 와 같은 상태 객체).

표에 함수가 없는 칸(공통 끝으로 바로 감): 진입 118·135·144 · 키 104·115~118·124·130~133·136·138~140 · 그리기 104·118·133·144.
상태 1 은 표 밖이지만 틀 처리 나무에 `1 → 0x13f08` 이 있다.

### 2a. 상태 객체 (장면+0x18) — 확정
- 0xbcb48(o, s): `o+0xc = o+8; o+8 = s; o+0x18 = 1` → **나중에 부른 것이 먼저 간다**. 두 번 부르면 앞의 것이 +0xc(= 장면+0x24, "다녀올 곳 뒤 돌아갈 상태")에 남는다.
  B 의 "줄 [130, 114]" 는 `next=114, 뒤=130` 뜻: **114(이벤트 재생)를 먼저 하고 끝나면 +0x24 의 130 으로 간다**.
- 0xbc9c8(o): 현재(+4) ≠ 다음(+8) 이면 `+0x10 = 옛 현재(장면+0x28 = 이전 상태), +0x14 = 0(상태 안 틀 수, 장면+0x2c), +4 = 다음` 하고 1(진입) 을 돌려준다.

### 2b. 상태 100 진입 0x1c154 = 경기 뒤(또는 장면 첫) 재진입 분기 — 확정
