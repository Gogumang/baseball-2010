## 요약
경기 장면 0x104 의 상태 7~0x23 을 진입(0xd04bc)·키(0x52dac 분기)·갱신(0xd0530)·그리기(0xd05a0) 네 표로 모두 대응시켰고(2절), 상태를 바꾸는 호출 43곳과 메시지 0~3·0x6aa·0x76c/d 를 따라가 **전이 표**를 만들었다(8절). 이름 없던 다섯 상태의 정체: **0xc(12) = 경기 시작 인트로**(적재 상태 8 끝에서 모드 1~4 만, 270→0 을 5씩 54틱, 마지막 12틱 네 계단 흐려짐, 효과음 61, OK 건너뛰기, 라이벌 짝(0xd8a90 = 0-1·2-7·3-6·4-5·8-9)이면 team_logo 9프레임 띠) · **0x13(19) = 맞은 직후**(0x11 → 메시지 0x6aa 판정 → 0x13 → 늘 0x17, 8틱 또는 공 틱 조건, OK 건너뛰기) · **0x18(24) = 3아웃마다 오는 공수 교대 판이자 1회초 시작 판이자 경기 끝 결과 판**(틱 0 에 예약 교체 적용·이어하기 자동 저장, 70틱 운동장 뒤 점수판, OK → 경기 끝 0x19 / 아니면 0xd; 경기 끝이면 10틱 입력 잠금, 점수 (W/2∓64·67, H/2−7) 와 승·패·세 투수 3줄 st+0x44/0x50/0x5c) · **0x1e(30) = 몸에 맞는 공 뒤 20% 벤치 클리어링**(양 팀 18명이 더그아웃 0xcfaf8 에서 투수판으로, 틱 10·30·60·70·80·100 단계, OK 건너뛰기) · **0x21(33) = 자동진행 중계**("공격팀(PLAYER/COM)" 은 공격 쪽이 사람 팀인지 표시, 속도 v = 기록+0xbc 0..2 → 8/4/1틱마다 한 걸음, 좌우로 바꿈, CLR → "자동진행을 중단하시겠습니까?"). 곁가지로 0x22 = 메인메뉴로 나가기, 0x23 → 자동진행 전환, 0x8 = 자원 적재, I-controls 의 "0x16 = 타구 연출" 은 **교체 연출**로 정정했다.
**남은 것**: 0x20 에 들어오는 길(못 찾음), 0x18·0x21·0xc 그림의 img_text 번호(388·389·329, 0xb9, 0xc1·0x86)가 무슨 글자인지(그림 확인 안 함), 0x3b80c 띠 9단계의 칸별 좌표, 0x21 속도 칸·안내 띠의 정확한 좌표, 0x13 의 +0x199a 뜻, 0xae3e8(B) 의 세부 가지, 0x10 메시지 8 두 가지의 뜻. 0x13·0x12 그리기의 공 부분은 궤적이라 읽지 않았다.


## 1. 선행 노트에서 모은 것 (출처만)
- 상태 변수: 경기 장면 this+0x1c = 현재 경기 상태, this+0x18 = 상태 객체, 0xbcb48/0xbcb49(this+0x18, n) = 다음 상태 예약, this+0x31 = "상태 바뀐 틱" 플래그 (I-controls 1b·4).

### 2-1. 상태를 바꾸는 길 — 메시지 0x509a0 의 0~3번 — **확정**
상태 예약 0xbcb48(obj, n): `obj+0xc = obj+8(이전 예약), obj+8 = n, obj+0x18 = 1` — obj = 경기+0x18 이므로 경기+0x20 = 다음 상태, +0x24 = 그 전 값. 다음 틱 0xbca04/0xbc9c9 가 +4(경기+0x1c) 로 옮기고 경기+0x31 을 세운다.
경기 장면 메시지 0x509a0(받는곳, 번호, 인자) 중 상태 관련:
| 메시지 | 위치 | 하는 일 |
|---|---|---|
| 0 (인자 n) | 0x50c08 | **상태 n 으로 바로** (0xbcb49(+0x18, n)) |
| 1 (인자 = 지금 상태) "확인" | 0x50c18 | 인자 0xe → 상태 **0xf**, 이어 돌발 객체 +0xf28 있고 0x8f158 참이면 **0x1b** 로 덮어씀. 인자 0x18 → [경기+0x1780]+0 바이트가 0 일 때만 `n = 0xae3a0(경기 로직 +0x214)`, n == 0xd 면 +0x197c = 0xf, 상태 n. 그 밖 인자는 무시 |
| 2 "경기 끝 요청" | 0x50cb0 | +0x1104(모드 쪽 값) ∈ {5,6} 이면 **0x19**. 아니면 0xb69b0(st,0) == 0xb69b0(st,1)(두 팀 점수 같음) 이면 무시, 다르면 **0x19** |

## 5. 상태 0x18 (24) = **공수 교대 / 경기 끝 화면** — 확정(흐름·분기) / 좌표 일부 유력
Q0 의 "경기 끝 직전(→25)" 는 반쪽만 맞다. 3아웃마다 들어오고, 경기가 끝났으면 같은 화면이 결과 화면이 된다.

**들어오는 길**: 메시지 3 "3아웃"(0x50c94: st[6]=3, +0x197c=0xf → 0x18) · 상태 0xc 갱신/키(0x39f0e·0x39bb2, 아래 3절) · 상태 0x21 갱신(0x48544, 자동진행 한 반 이닝 끝).

**진입 0x3ac90**:
- +0xf98 객체 +4·+5 = 0, 0xa276c(+0x204, 1), 점수판 객체 +0x1ec vt0xc(0xf0, 0x186 − 화면높이/2) (위치 맞춤).
- 0xb67d0(st): 한 타석 칸들 지움(st+0x20·+0x80 = −1, 볼·스트 등 바이트 0, st[7] = 1).
- `0xb68fc(st)`(경기 끝) 거짓이고 `0xb6b6c(st)`(아웃 > 2 → 초/말 뒤집기·이닝++) 참이면: 주자 모두 지움 0xa9250(+0x20c), 점수판 +0xf10 +0x18 = st[0x6b](이닝), 0x76fc4, **반 이닝 투구 수 초기화 0xa5b00(+0x230)**, 돌발 객체가 있으면 0x8f628.
- 조작 객체 뒤집기: `+0xfa0[st[9]]`(새 공격 쪽) +0xc = 0, `+0xfa0[st[10]]` +0xc = 1 (0 공격 / 1 수비, I 문서 뜻). 팀 포인터 +0x220/+0x224 도 st[9]/st[10] 로 다시 넣는다.

**갱신 0x4f928** (틱 = 경기+0x2c):
- 경기 끝이면: `경기+0x32 = (틱 ≤ 9)` — **처음 10틱은 상태 고정**(0xbc9c8 이 예약을 되돌림 → OK 가 먹지 않는다). 효과음 13 은 안 낸다.
- 경기 끝이 아니면 **틱 0 에서 한 번**:
  1. 0xaebe4(팀0, 0)·0xaebe4(팀1, 0) — 예약된 교체 적용(R4 대타 확정 함수).
  2. 모드(+0x1104) ∈ {1,2,8,9} 이고 이전 상태(경기+0x28) ≠ 9 이면 **이어하기 자동 저장**: 0x1fdec(저장), 모드 1 → 칸 0x32·0x33(두 팀, 0x1fdb0) + 0x33(st) / 2 → 0xb(+0xf08)·0xc(두 팀)·0xd(st) / 8 → 0x29·0x2a / 9 → 0x3d·0x3e, 0x4e8b0, 0x22754(저장, 1) 파일 쓰기.
  3. 이전 상태 == 0x21(자동진행) 이면 +0x1784 = 1.
  4. `0xc2198(자동진행 +0x1780, 1)` 참(자동진행 계속) → +0x1784 = 1, 점수판 위치를 0xcfa8c (20000, 24500) 로, 0x47cc8(그림 다시 적재), **상태 0x21**. 거짓이고 +0x1784 == 1 이면 메시지 1(인자 0x18) 을 스스로 보냄 → 곧바로 다음(0xae3a0). 둘 다 아니면 사람이 OK 를 누를 때까지 기다린다(I 조작표 0x18: OK → 1(상태)).
  5. 0x3fac4 (카메라를 투수판 쪽으로 1%/틱, R3).
- 매 틱(경기 끝 아님): 0x4f7ac (틱 2 에서 효과음 13 징글, R2). +0x1110++.
- **나가기**: OK → 메시지 1(0x18) → 0xae3a0: 경기 끝 → **0x19 정산**, 아니면 **0xd**(다음 반 이닝 첫 타석, +0x197c = 0xf).

**그리기 0x4fe9c**:
- +0x1784(자동진행 중) 이면 0x4258c(상태 0x21 화면) 만 그리고 끝.
- 경기 끝 아님: 0x4fb8c = 운동장 전경(0x43010 야수 그리기 두 번, 0xbe6a1, 투수 0xae83c…) — 수비수가 제자리로 가는 모습. **틱 ≤ 69 동안은 이것만**. 틱 70 부터 0x41440(경기, 0, 0, 0,0,0)(점수판 틀) + 두 팀 판 0x42364 / 0x420dc 를 (W/2 − 판폭/2, H/2 − 2) 와 (W/2 + 판폭/2 − 76, H/2 − 2) 에 — st[9](초 0 / 말 1)에 따라 좌우가 바뀐다(초면 왼쪽 0x42364, 말이면 왼쪽 0x420dc). 판폭 = +0x1018 스프라이트 프레임 상자(0x94a64(…, 0, 4)).
- 경기 끝: 0x41440(경기, 0, 3, …) 뒤 **결과 판**:
  - 두 팀 점수 `0xb69b0(st, 0/1)` 를 숫자 그리기 0x585ac(skin, 스프라이트, 프레임 0x46, 값, x, y, 6, …, 2) 로 **(W/2 − 64, H/2 − 7)** 과 **(W/2 + 67, H/2 − 7)**.

## 8. 경기 장면 상태 전이 표 — 확정(표시 없는 줄) / 유력(표시)
상태 바꿈은 모두 0xbcb48/0xbcb49(경기+0x18, n) 한 곳으로 모인다. 경기 코드(0x37000~0x54000) 안 호출 43곳 + 메시지 0 을 전부 따라가 만든 표다. "로직 다음" = 경기 로직(+0x214) 의 두 판정 함수:
- **A = 0xae24c** (인플레이 없이 한 공 끝 — 0x12·0x1e·0x1a 쪽): 경기 끝(0xb68fc) → 0x18 · 홈런더비(st[1]=7) → 0xd / **0x1a**(기회 끝) · 아웃 > 2 → 0x18 · st[0xb] ∈ {3 볼넷, 4 사구} → **0x17**(밀어내기 주루) · st[0xb] ∈ {5, 0xd}(삼진 쪽) → **0xd**(다음 타자, 0xa8024 기록) · 그 밖 → **0xf**(같은 타석 다음 공).
- **B = 0xae3e8** (인플레이 0x17 끝): 경기 끝 → 0x18 · 홈런더비 → 0xd/0xf/0x1a · 아웃 > 2 → 0x18 · 그 밖 → 0xd 또는 0xf (st[0xb]·st[0x26] 로 가름, 세부 유력).
- **C = 0xae3a0** (0x18 에서 OK): 경기 끝 → 0x19, 아니면 0xd.
