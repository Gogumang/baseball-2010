## 요약
타자편 경기 뒤 인기도(타석 점수 0xa59c0 + 경기 끝 0xa690c)와 사기(0xa719c 안 0xa7396~)를 디스어셈으로 처음부터 다시 읽었다(확정).
**사기는 웹과 같다.** 다른 점은 동점 한 줄뿐이다(원본 0xb69c8 은 동점이면 측 0 이 이긴 것으로 친다).
**인기도는 웹과 네 군데가 다르다.**
- 타점 표 [3,4,5,6] 은 홈런에만 쓰고, 칸은 루타가 아니라 득점 수다(솔로 3 … 만루 6).
- 홈런이 아니면 득점 점수(1점 +1, 2~3점 +2)에 루타 점수(1~3)를 더한다. 안타가 아닌 타점도 친다.
- 끝내기는 홈런이면 5, 아니면 4 다.
- 경기에서 삼진이 2개 이상이면 점수 −1 이다(G+0x108).
웹 주석의 "진루 보너스 r6" 은 루타 점수였다.
드래고나(해금 id 3)는 로컬에 여는 조건이 없다. 온라인 선물함(메인 메뉴 하위 상태 31, 0x2bb48)이 받는 "히든 오픈" 64비트 마스크로만 열린다 🌐.
투수 GP 아이템은 장어구이 제구 · 붕붕드링크 구속 · 빌리언XZ 변화 · 고려인삼 체력(+0xc~+0x12)을 올린다. 한계 행은 보직(선발 800 / 구원 850·850·850·600)으로 고른다.
필살타법 창(상태 0x6c, 키 처리 0x17828)은 "칸 i == 배운 수" 일 때만 훈련시킨다. 그래서 최고 레벨이면 모든 칸이 StrMODE[63] 으로 막힌다. 인기도 100/500/1000/1500 조건과 G 부족 막음도 이 창에 있다(웹에 없음).

## 1a. 타자편 인기도 — 타석 점수 0xa59c0 + 경기 끝 0xa690c (모드 4) — **확정**

### 타석 점수 0xa59c0 (호출은 정산 0xa8024 의 0xa8c2a 한 곳, 모드 4 일 때만)
정산 0xa8024 는 플레이 이벤트 목록(state+0x30[], 개수 +0x2c)을 센다 (0xa8096~0xa80f6):
`0xf → [sp+0x28]++` · `8 → [sp+0x24]++, [sp+0x2c]++` · `6 → [sp+0x2c]++` · `0xd·5 → [sp+0x30]++` · `5 → [sp+0x20]++`.
- 이벤트 0xf 는 **득점 처리 0xa5c34 가 1점마다** 넣는다 (0xa5c70~0xa5c7c `str #0xf,[r6+0x30+4n]; n++`) → [sp+0x28] = **이 플레이 득점 수**.
- [sp+0x24] = 홈런 수, [sp+0x2c] = 안타 수(홈런 포함), [sp+0x30] = 아웃 수, [sp+0x20] = 삼진 수.
- 0xa8192~: 홈런이면 `[sp+0x14]=1, [sp+0x10]=4`, 아니면 안타일 때 루타 수를 [sp+0x10] 에.
- 호출 0xa8c0e~0xa8c2a: `r1 = 아웃 수, r3 = 안타 ? 루타 : −1, 스택0 = 득점 수, 스택1 = 홈런 수`.

```
0xa59e4  0xa56dc(G, 타자, 1) 거짓이면 끝                     ; 내 선수 타석만
홈런 > 0:                                                      ; 0xa59f4
   끝내기(0xb68fc) → +5
   아니면 득점 1 → +3 · 2 → +4 · 3 → +5 · 4 → +6              ; 솔로·투런·스리런·만루
   끝 (아래 안 봄)
홈런 아님:                                                     ; 0xa5a3e
   끝내기 && 득점 > 0 → +4, 끝
   득점 1 → +1 · 득점 2~3 → +2                                 ; 0xa5a58~0xa5a7c (안타 아니어도: 밀어내기·희생플라이·땅볼 타점)
   안타면 루타 1 → +1 · 2 → +2 · 3 → +3                        ; 0xa5a7e~0xa5ab0 (득점 점수에 더함)
   안타 아니면 아웃 > 1 → −1, G+0x118(병살)++                  ; 0xa5ab2~0xa5acc
   아웃 > 0 && 0xa97a0(주자판, 2) → G+0x11c(득점권 아웃)++      ; 0xa5ace~0xa5aea
```
(점수는 모두 G+0x120 에 더한다 — `movs r3,#0x90; lsls r3,#1`.)

## 1b. 사기 — 0xa719c 안 0xa7396~0xa7440 — **확정** (무승부 한 줄만 유력)
흐름 0xa719c: `0xa690c(인기도) → 0xa6218(평판) → 사기` 순 (0xa738c·0xa7392).
```
a73b0  rival = 0xb8f68(팀0, 팀1)       ; 표 0xd8a90 = [0,1, 2,7, 3,6, 4,5, 8,9], 두 방향 모두 봄
a73bc  c = 0xb69c8(state) ? +5 : −7
a73ce  if rival: c *= 2
a73d4  p = s8 career+0x4a              ; 이번 경기 인기도 변화
a73e6  (모드 3 이고 선발이고 p>0 이면 p = trunc(p/2) — 투수편 전용, P1 5-4)
a7408  if c < 0 && p > 1: c += trunc(p/2)
a7418  if 스킬 6(행운) 보유 (0xa4bf8): c += 1
a742a  career+7 = c (s8, 이번 변화량)
a742e  사기 = 0xa3a44(career, 0xa3a24(career) + c)   ; 팀 레코드(0x1f988(전역, career[1])) +2, clamp 0..100
```
- **승리 판정 0xb69c8**: `승자측 = 점수(측1) > 점수(측0) ? 1 : 0` 그리고 `state[0x31+승자측] == 0`(사람 조작 측)이면 참.
  → **동점이면 측 0 이 이긴 것으로 친다.** 내가 측 0 이면 무승부도 +5, 측 1 이면 −7. (측 0 = 원정/초 공격 — 0xb68fc "말 공격 홈" 해석과 맞춘 **유력**. 원본 모드 4 에 무승부가 실제로 나는지는 이 절에서 안 봤다.)
- 사기는 선수 칸이 아니라 **내 팀 레코드 +2 (s16)** 에 있다 (getter 0xa3a24 · setter 0xa3a44 가 0x1f988(전역, career[1]) 로 팀 레코드를 찾음). 상한 100 (0xa3a56 `cmp r4,#0x64`).

## 3. 투수 GP 능력 아이템(장어구이~고려인삼) 이 올리는 칸 — **확정**
0xa4488(나리, r6 = 아이템 번호 0~9, 점프표 0xd80e8). 칸 0~3 가지 0xa4528:
```
a4528  rec = 0x1fc74(전역, career[0])          ; 내 선수 레코드
       rec[+0xc + 2k] = min(rec[+0xc+2k] + 10, 999)   ; k = 아이템 번호 그대로
       if 0xb6414(rec, k, 0) > 한계[k]: rec[+0xc+2k] = min(한계[k], 999)
a455c  알림 글 = StrMODE[모드4 ? 0x23+k : 0x28+k] + " " + "6" + StrMODE[83]
```
- 투수 레코드 능력 칸 순서 = **0 제구 · 1 구속 · 2 변화 · 3 체력** (P1 269행 `0xb570c(로스터, 칸 0 = 제구)`, V5 검증 0xb5942 칸 대응, 알림 이름 StrMODE[40~43] = 제구·구속·변화·체력).

## 4. 필살타법 창(상태 0x6c) 최고 레벨 가드 — (작업 중 메모)
- 훈련 칸 4 선택(0x12e02~0x12e2e, 모드 4)은 레벨 검사 없이 `0xbcb48(장면, 0x6c)` 로 상태 0x6c 를 열고 창 탭(+0x188)=0. 모드 3 은 0x12dc0~ 에서 상태 0x78.
- 관리 장면 키 분기 0x1cdec: `상태−0x66` 점프표 0xcc7e0 → **0x6c → 0x1d0d4 → 0x17828** (키 처리). 0x7b → 0x17cec(선수정보의 필살타법 선택 창), 0x7d → 0x18dd8 → 0x17f5c(훈련 결과, 0xa3bac 호출).
  (G 문서의 "0x17828 은 투수 구질 창" 은 정정 — 0x17828 은 상태 0x6c 키 처리, 탭 2 만 구질.)
