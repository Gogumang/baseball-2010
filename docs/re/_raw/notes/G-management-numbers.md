# G. 관리 메뉴 수치 (훈련·휴식·외출·부상·질병)

## 요약
훈련(0x17f5c → 적용 0xa3bac), 휴식(0x18e3c · 회복 0x1b308), 외출(가드 0x16c64 · 효과 0x15234 · 입원 회복 0x1575c),
훈련 부상(0x1b4c4), 질병 발생 조건 22(0xadb32), 경기용 능력치(0xb570c)를 디스어셈으로 다시 확인했다.
웹판 수치 대부분(훈련 상승·사기, 필살타법 표, 휴식 +10~15, 회복 60/30·90/70, 외출 효과 표, 부상 확률 표)은 원본과 같다.
**새로 풀린 것 / 웹과 다른 것**:
1. 부상 −60%·질병 −30% 는 `0xb6414` 가 아니라 경기용 능력치 `0xb570c` 에서, **장비·스킬 보정 뒤에** 곱한다. 둘 다면 **둘 다 차례로** 깎는다.
2. 같은 곳에서 **사기 감소 보정**이 있다: 사기 31~50 −10%, 11~30 −20%, ≤10 −50% (웹판 없음).
3. 외출 **빈 장소(440~444)는 행동을 쓰지 않는다** (0x1c014, 플래그 +0x167). 웹판 추정("쓴다")과 반대.
4. 외출 효과 난수 순서 인기도→평판→사기 **확정** (0x15234). 입원 회복 90%/70% **확정** (0x1575c).
5. 필살타법 최고 레벨 가드는 원본에 없다 — 레벨 4 에서 표 밖(필요 380회·비용 0)을 읽는다.
6. 질병 발생 확률(이벤트 490 조건 22): 사기 >70 0% · 51~70 2% · 31~50 4% · 11~30 7% · ≤10 14%, 유리몸 +10, 행운 −20.
7. 질병 쿨다운 +0x7c 는 경기마다 −1 (0x4f3a6), 쿨다운 동안 이벤트 490 차단 (0xad01a) — 확정.
8. 부상 중 치른 경기 수 +0x1b6 을 세고, 20경기가 되면 부상 엔딩 0 (0xa3a84) — 웹판 없음.
9. 보상 11 값 ≥0 → bfa55(0,4)+1 로 질병 종류 균등 선택 (0x8c14e) — 확정.
10. GP 능력 아이템 인자 6·8 은 알림 글에 찍히는 숫자다(실제 상승은 +10). 한계 비교는 장비·스킬 **빼고** 한다 → 웹 gpItems 와 다름.
11. 외출 소지금 검사는 보험증서를 보지 않는다 (0x16d42) → 웹과 다름.
12. 행동 플래그 +4 는 경기마다 지운다 (0x4f158).
남은 것: 필살타법 최고 레벨을 필살타법 창(상태 0x6c)에서 막는지(0x17828 은 투수 구질 창이었다), 0xb570c 의 마지막 감소 인자 [sp+0x24] 가 타자편에서 무엇인지.

(아래 항목은 풀리는 대로 덧붙인다)

## 1. 트레이닝

### 1-1. 상승치·사기 감소 — 확정 (0x17f5c, 적용 0xa3bac)
- 사기 감소: `bfa55(5,8)` → [sp+0x38] (0x186c4). 필살타법(칸 4)은 `bfa55(9,13)` (0x17fd8).
- 상승: 타자(모드 [this+0xcc]==4)에서 칸 2·3(수비·주루)이면 `bfa55(5,8)`, 아니면 `bfa55(4,7)` (0x186e0~0x18704).
  (투수 모드는 칸 3 만 5~7.)
- 타입 보너스 +1: 칸 0 & 타입 0, 칸 1 & 타입 1 (0x18736~0x187b6, 타입 = 레코드+0xb >>5). StrMODE[194].
- 서브 아이템 +0x58+칸 → 상승 +2 (0x187f6). 자동안마기 +0x5c → 사기 감소 −1 (0x188cc).
- 스킬 0(병아리, a4bf9 = 레코드+0x14 비트): 상승 +1, 사기 감소 −1 (0x1891c). 스킬 3(몹쓸몸, a3a75 = 커리어+0x1b8 비트): 상승 −2, 사기 감소 +2 (0x1898e).
- 적용: `a3bac(선수, 칸, 상승, 사기감소)` (0x18a1e).
  - 칸 0~3: `능력[칸] = min(능력+상승, 999)` (0xa3c0c, 리터럴 0x3e7). **타입 한계로 자르지 않는다.**
  - 사기: `a3a44(사기 − 감소)` → 0..100 으로 자름 (0xa3a44).
- 훈련 횟수 +0x4b+칸 ++ (0x18a5c).
- 비용: 칸 0~3 은 돈·G포인트를 쓰지 않는다.
- 웹: `training.ts:106-119` 같음. 차이 없음.

### 1-2. 필살타법 — 확정 (0xa3c26)
- 세션 +0x200, 레벨 +0x201. 필요 횟수 `0xd7e92` s16 [4,5,6,7], G 비용 `0xd80e1` s8 [−5,−7,−9,−12]×100.
- G포인트 += 비용, 0..99999 로 자름 (0xa3c78, 리터럴 0x1869f) → 모자라도 막지 않는다.
- **최고 레벨 가드 없음**: 레벨 4 면 `d7e92[4]=380`, `d80e1[4]=0` 을 읽는다(표 밖 쓰레기값). 가드도 0x12e40 에서 칸 4 는 한계 검사를 건너뛴다(`cmp r1,#3; bgt`).
  → 웹판 `'훈련완료'` 가드(training.ts:87-89)는 원본에 없는 안전장치. 원본대로면 레벨 4 에서 380회마다 레벨 5 가 되고 비용 0.
  메뉴 쪽(필살타법 창)에서 막는지는 미확인.

### 1-3. 훈련 가드 — 확정 (0x12d8a~0x12f28)
- 사기 0 → StrMODE[193] (0x12d90, `a3a25()==0`).
- 칸 0~3: `b6414(선수, 칸, 0)` ≥ 한계 → StrMODE[192]. 한계 = 표 `0xcc502`[타입×4+칸] ×10 (0x12e5e).
  `b6414` 의 플래그 0 은 **마선수 레벨 배율만** 적용하고 장비·스킬 보정 전 값을 돌려준다(0xb648c `cmp r2,#0; beq`).
  육성 선수는 마선수 비트(+0xa bit6)가 없어 배율도 없다 → 사실상 기본 능력치.
- 800 계열 한계는 **거절 판정에만** 쓰이고, 상승 자체는 999 로만 자른다(1-1). 웹 `abilityLimit.ts`·`training.ts:90-91` 과 같음.
- 능력 상한 999: `0xa3c18` 리터럴 0x3e7 확정.

## 2. 휴식 — 확정

### 2-1. 사기 회복 (0x18e3c)
- `bfa55(10,16)` → `a3a45(사기+값)` (0..100). 웹 `outing.ts:79` 같음.
- 가드 (메뉴 점프표 0xcc540 칸 2, 0x12682): 사기 == 100 이면 StrMODE[91], 아니면 StrMODE[90] 질문. 아파도 거절. 웹 같음.

### 2-2. 회복 판정 (0x1b308, 결과 창 닫을 때)
- 질병(+5 ≠ 0): `bfa55(0,100)` ≤ 59 이거나 남은 기간(+6)==0 → 치료: +5=0, +6=[0xcc333]=0, **+0x7c=20**, StrMODE[206]+[185+종류].
  아니면 +6 −1 (바닥 0).
- 부상(+0x1b5 > 0): 기간 먼저 −1, `bfa55(0,100)` ≤ 29 이거나 기간 0 → 치료: +0x1b5·+0x1ce·+0x1b6 = 0, "부상에서 회복 되었습니다."(0xcca04).
- 웹 `recovery.ts` 같음.

## 3. 외출

### 3-1. 가드 순서 — 확정 (0x16cf0)
1. 인기도 `0xcc402`[장소] u16 > 인기도 → StrMODE[62] (%d).
2. 장소 ≤2 이고 비용 |`0xcc344`[장소]| > 소지금(+2) → StrMODE[77]. **보험증서(입원 무료)를 보지 않는다.**
3. 장소 2(입원)이고 질병·부상 둘 다 없음 → StrMODE[196].
4. 장소 1(외식)이고 사기 == 100 → StrMODE[91].
- 웹 `outing.ts:23-36`: 순서가 다르고(사기 → 건강 → 소지금), 보험증서면 소지금 검사를 건너뛴다 → 원본과 다름(소지금 200만 미만이면 원본은 보험증서가 있어도 막힘).

### 3-2. 효과 표 — 확정 (0x15234)
- 난수 순서 **인기도 → 평판 → 사기** (0x1524c, 0x1526e, 0x1528e 세 번의 bfa55). 웹 주석의 "추정" 은 확정으로 바꿀 수 있다.
- 표 (s8 쌍 [a,b)):
  | 장소 | 인기도 0xcc358 | 평판 0xcc34e | 사기 0xcc33a | 소지금 0xcc344 (×100만) |
  |---|---|---|---|---|
  | 0 경기장 팬미팅 | 4~6 | 0 | 2~3 | −5 |
  | 1 번화가 외식 | 0 | 0 | 25~30 | −1 |
  | 2 병원 입원 | 0 | 0 | 3~5 | −2 |
  | 3 학교 야구교실 | 1~3 | 3~5 | −(8~10) | 0 |
  | 4 방송국 CF | 2~4 | 8~10 | −(16~20) | +8 |
  장소 3·4 는 사기 난수 부호를 뒤집는다 (0x152e0).
- 서브 아이템(+0x5d+장소, 점프표 0xcc6c4): 0 인기도+2 · 1 사기+4 · 2 소지금+2(=무료)·사기+1 · 3 인기도+1·평판+1 · 4 소지금+4(=+400만). 부호 뒤집기 **뒤에** 더한다.
- 반영: 인기도 +0x48 (0..9999), 평판 +0x62 (0..999), 소지금 +2 (0..9999), 사기 a3a45 (0..100).
- 끝에 외출 횟수 +0x6a ++, **행동 플래그 +4 = 1** (0x156e4~0x156f4).
- 웹 `outingPlaces.ts` 표 값 같음. 13행 주석("우리가 정한 값")은 낡은 문구.

### 3-3. 입원 회복 — 확정 (0x1575c)
- 장소 2 일 때만. 구조는 휴식과 같고 질병 `≤0x59`(90%), 부상 `≤0x45`(70%). 웹 `recovery.ts:17` 같음("추정" 떼도 됨).

### 3-4. 빈 장소 — 확정: 행동을 쓰지 않는다
- 0x16c9c: 장소 칸 0(이벤트)을 고르면 `8ce58` 로 대기 이벤트를 찾고, 없으면 `8bdc8(440+장소)` 를 실행하고 this+0x167 = 1.
- 이벤트 끝 처리 0x1c014 (상태 0x71):
  - +0x167 == 0(진짜 이벤트) → 커리어 +4 = 1(행동함), 상태 0x69(메인 메뉴), 외출 횟수 +0x6a ++.
  - +0x167 != 0(빈 장소) → 플래그만 지우고 상태 0x71(장소 화면)으로 돌아간다. 행동·횟수 없음.
- 웹: RALPH_PROGRESS 534 "행동을 쓴다(추정)" — 원본과 반대.

## 4. 부상·질병

### 4-1. 부상 발생 — 확정 (0x1b4c4, 훈련 결과 창 닫을 때)
- 이미 부상이면 건너뜀. 사기(훈련 뒤 값) 구간: >70 0 · 51~70 1(필살 3) · 31~50 3(5) · 11~30 5(8) · ≤10 10(16) %.
- 유리몸(스킬 4) +5, 행운(스킬 6) −20 (바닥 0). `bfa55(0,10000) < 확률×100` → +0x1b5=3, +0x1ce=3, +0x1b6=0, "!C부상을 당했습니다."(0xcca24).
- 웹 `condition.ts:60-93` 같음. 경기 뒤에는 굴리지 않는다(웹도 같음).

### 4-2. 질병 발생 — 확정 (조건 22, 0xadb32)
- 이미 아프면 거짓. 나만의리그: 사기 >70 0% · 51~70 2% · 31~50 4% · 11~30 7% · ≤10 14%.
- 유리몸 +10, 행운 −20 (바닥 0). `bfa55(0,100) < 확률` 이면 참.
- 이벤트 490 (trigger 0 관리 화면, 1년 15경기 ~ 13년 45경기, 반복). 보상 11 → +5 종류, +6 = `0xd4d98`[종류] = 3, **+0x7c = 20** (0x8c730).
- 부상/질병 "비율" 이란 것은 없다: 부상은 훈련 뒤, 질병은 관리 화면 이벤트로 따로 굴린다.

### 4-3. 능력치 감소 — 확정 (0xb570c, 경기용 능력치)
- `b6414(선수, 칸, 1)` (마선수 배율 → 장비 → 스킬) 뒤, 나만의리그(모드 3·4)이고 내 선수(+0xa bit7)면:
  1. 질병(+5≠0): `v += (−30·v)/100` (0xb5784)
  2. 부상(+0x1b5>0): `v += (−60·v)/100` (0xb57b4) — **둘 다면 차례로 둘 다**
  3. 사기: >50 없음 · 31~50 `v += v/(−10)` · 11~30 `v += v/(−5)` · ≤10 `v −= v/2` (0xb57c4~0xb5800)
  (나눗셈 0xca7b5 는 0 쪽 버림.)
- 뒤이어 인자 [sp+0x24](체력 계열로 보임) 구간 감소: 35~54 −10%, 20~34 −30%, 1~19 −50%, ≤0 −90% (0xb58e6). 타자편에서의 값은 미확인.
- 웹 `condition.ts:41-52`: 부상/질병 중 **하나만**, **장비 보정 전**에 곱하고, **사기 감소가 없다** → 세 가지 다름.

### 4-3b. 질병 종류 고르기 — 확정 (보상 글 만들기 0x8c14e, 적용 0x8c718)
- 보상 11 의 값이 ≥0 이면 `r6 = bfa55(0,4)`, 값 := r6+1 을 **레코드에 다시 쓰고**(0x8c214 `strh r5,[r3,#2]`),
  StrMODE[207] "다음 질병이 발생했습니다 [StrMODE[186+r6]]" 를 만든다. 값 <0 이면 치료 글(StrMODE[206]).
- 그 뒤 0x8c718 이 값 >0 → +5 = 종류(1~4, 감기·몸살·식중독·배탈 균등), +6 = `0xd4d98`[종류] = 3, +0x7c = 20. 값 ≤0 → 치료.
- 질병 기간 3 은 표 `0xd4d98` = [0,3,3,3,3] 로 확정. 웹 `eventReward.ts:57,106` (random.pick) 같음.
- 부상 기간 3: 0x1b590 `movs r1,#3` 로 확정 (+0x1b5·+0x1ce 둘 다 3).

### 4-4. 경기 뒤 카운터 — 확정 (0x4ea0c 안, 0x4f344~0x4f3b2, 모드 3·4)
- 부상 중(+0x1b5>0)이면 **+0x1b6 ++** (부상 상태로 치른 경기 수).
- +0x54(이글아이 남은 경기) −1, 상한 99.
- **질병 쿨다운 +0x7c: 경기마다 −1 (0 에서 멈춤)** → 웹 `playerCareer.ts:337` 과 같음. "추정" 뗄 수 있다.
- 부상 기간(+0x1b5)은 경기로 줄지 않는다. 휴식·입원(2-2, 3-3)으로만 준다.
- 쿨다운 사용처 (0xad00e~0xad054, 이벤트 조건 검사): 쿨다운 > 0 이고 이벤트 id == 490(0xf5×2) 이면 조건 실패 → 쿨다운 동안 질병 이벤트가 안 뜬다.
  쿨다운 20 은 질병에 걸릴 때(0x8c730)·치료할 때(0x1b3b2·0x15842·0x8c748) 모두 넣는다. 웹 `storyScene.ts:91` 같음.
- 부상 누적 엔딩: 엔딩 판정 `0xa3a84` 가 +0x1b6 > 19(=20경기) 이면 엔딩 0(부상)을 돌려준다(0xa3a96 `cmp r3,#0x13`).
  5000G 이어하기(0x1bdc4)는 +0x1b5·+0x1ce·+0x1b6 을 0 으로 지운다.
  웹: +0x1b6 카운터와 부상 누적 엔딩(500)이 없다 (`seasonFlow.ts:11` 에 "아직 없는 것"으로 적혀 있음).
  StrMODE[212] "부상 상태로 경기를 계속 진행할 경우 선수 생명이 위험합니다" 가 이 규칙을 말한다.

## 4-5. 행동 플래그 (커리어 +4) — 확정 (보충)
- 1 로 세우는 곳: 훈련 끝 0x18d70, 휴식 0x18fe0, 외출 기능 0x156f4, 외출 이벤트 0x1c052 (빈 장소는 아님).
- 관리 메뉴 0x1194a: +4 ≠ 0 이면 메뉴 칸 1·2·3(트레이닝·휴식·외출) 사용 가능 플래그를 0 으로 끈다.
- 지우는 곳: 경기 끝 0x4f158 `strb r2(=0),[r1,#4]` — **경기마다** 무조건 0.
  웹 `playerCareer.ts:339-340` 은 2경기마다 푼다. 관리 화면이 2경기마다만 열린다면 결과는 같지만, 원본 기준은 "경기 한 번"이다 (관리 화면 주기는 이 주제 밖, 미확인).

## 5. 아이템·컨디션

### 5-1. GP 능력 아이템 (0xa4488) — 확정
- 한계 표: 타자(모드 4) `0xd80c6` = [80,80,80,80 | 80,85,75,75] ×10 (행 = 타입), 투수 `0xd80be` = [80,80,80,80 | 85,85,85,60].
- 칸 0~3 (0xa4528): `능력[k] = min(능력[k]+10, 999)` → `b6414(선수,k,0)` > 한계면 `능력[k] = min(한계,999)`.
  칸 4 모든 능력치 (0xa458c): 칸 0..3 에 같은 처리.
- **`b6414` 플래그 0 은 장비·스킬을 빼고 마선수 배율만 적용**한다(1-3 참고). 육성 선수는 곧 기본 능력치 비교.
  → 웹 `gpItems.ts:55-64` 는 `effectiveAbilityOf`(장비·스킬·부상 포함)로 비교해, 장비가 있으면 기본값을 한계 아래로 **깎는다**. 원본과 다름.
  웹 주석 "장착 보너스 포함 0xb6414" 도 잘못. 올바른 동작: 기본값이 한계를 넘을 때만 한계로 내린다.
- **인자 6·8 의 뜻**: 알림 글 끝에 붙는 **숫자**다. 글 = StrMODE[35+k](투수 40+k) + " "(0xd80bc) + `bc73d(6)` + " " + StrMODE[83].
  `0xbc73c → 0xbc6c0` 은 10진 정수를 붙이는 함수(음수면 '-')다. 모든 능력치는 StrMODE[39] + 8.
  즉 원본은 **+10 을 올리면서 "히트 6 상승하였습니다" / "모든능력치 8 상승하였습니다" 라고 표시**한다(원본 글 버그로 보임).
  웹은 "+10" 으로 표시 (gpItems 알림). 원본 그대로 옮길지 결정 필요.
- GP 가격: 상점 0x14e54 가 `0xcc41b`[k (다른 모드 +10)] ×100 G. 값 [3,3,3,3,10,3,3,5,20,5] 확정. 웹 `gpItems.ts:25` 같음(13행 주석 "못 찾았다"는 낡음).
  G포인트 0..99999 로 자름(0x14e6c).

### 5-2. 서브 아이템·장비 가격 — 확정 (표 바이트 재확인)
- 서브 아이템 `0xcc430` **u16** [15,20,15,15,10,25,20,10,20,20] ×1000만. 웹 `subItems.ts:20` 같음.
  효과 적용 지점: 훈련 +0x58+칸(+2)·+0x5c(사기 −1) (1-1), 외출 +0x5d+장소 (3-2). 5~9 도 코드 확인 → 웹 subItems.ts:10 "추정" 뗄 수 있다.
  단 **보험증서는 소지금 검사(0x16d42)에서 무시**된다 (3-1).
- 장비 가격 `0xcc444` u16 (11칸 × 부위 행), 필요 인기도 `0xcc50a` [0,50,150,300,450,600,800].

### 5-3. 컨디션 표 60~100% (0xd88aa) — 확정: 마선수 전용
- `b6414`: `b63a0(선수)` = 마선수(+0xa bit6, `b633c`)면 레벨(+0xa & 0x1f), 아니면 −1.
  ≥0 이면 `등급 = 세이브[+0x13a + 레벨(+5 타자) ]`(s8, 0x1f1d9 객체), `v = v × d88aa[등급] / 100`. d88aa = [60,70,80,90,100].
- 육성 선수에는 적용되지 않는다(비트 없음). 웹 condition.ts:36 설명과 같음.
- 장비 보너스 `0xd8890` s16 [30,50,70,90,110,125,140,190,210,230,250] — 니블(바이트 +0x19+칸/2, 칸 짝수 = 상위 4비트, 홀수 = 하위 4비트) −1 로 인덱스, 니블 0 이면 보너스 없음, 999 로 자름 (0xb646c~0xb64a8). 플래그 1 일 때만. 웹 `equipment.ts:40,151` 같음.
- 스킬 보정(플래그 1): 스킬5 −100(바닥0) · 스킬7 +50(999) · 투수면 스킬22 칸0 +v/10 · 타자면 스킬20 칸2 −100.
