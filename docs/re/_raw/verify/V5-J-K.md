### J-3 경기진행 설정 · 판정 0xc1e04
- ✅ 저장 칸: 종류 s8[save+0x12c+m](0x96<<1), 값 s8[+0x146+m](0x12c+0x18+2), 타순 u16[+0x120+2m](0x90<<1), 이닝 u16[+0x124+2m](0x92<<1), 공격주자 [+0x128+m](0x94<<1), 수비주자 [+0x12a+m] — c1f3c~c2160 에서 직접 확인. m = 전역 0x1552ad8.
- ✅ 이닝: 값 0 → 늘 조작(c2028 → c2046), 값 1 → s8[상태+0x6b] > 2(c2032), 값 2 → > 5(c203e). 4회·7회부터 맞음.
- ✅ 상세 수비: 이닝 비트[이닝idx] 또는 (비트 8 && 이닝idx > 8) → 조작 (c214c~c2176). 공격: 타순(0xae85d ≤ 8) 비트 또는 공격주자 비트 루에 주자.
- ❌ **찬스 표가 공격/수비 조건을 빠뜨렸다.** 마스크는 6·4 가 맞지만(c1f8a `movs r6,#6`, c1fe2 `movs r6,#4`) 두 분기가 보는 팀이 다르다:
  - 값 0 (마스크 6): `s8[상태+0x31+s8[상태+9]] == 0` 일 때만 (c1f64~c1f80) — 상태+9 = **공격 팀**
  - 값 ≠0 (마스크 4): `s8[상태+0x31+s8[상태+0xa]] == 0` 일 때만 (c1fbc~c1fd8) — 상태+0xa = **수비 팀**
  - +9/+0xa 가 공격/수비 팀인 근거: 0xb6bc0 `strb r1,[r0,#9] ; strb (r1==0),[r0,#0xa]`, 0xb6ba4 공수 교대 때 +9 ↔ +0xa 맞바꿈. 상세 분기(c2058)도 `[+0x31+[+9]]==0` 이면 공격 쪽으로 간다 → +0x31+t == 0 은 "팀 t 를 사람이 조작".
  - 즉 **찬스 0 = 사람이 공격 중이고 2·3루에 주자(득점 찬스)**, **찬스 1 = 사람이 수비 중이고 3루에 주자(실점 위기)**. 1절 "2루 또는 3루에 주자 / 3루에 주자" 만으로 구현하면 공수 양쪽에서 다 조작권이 넘어온다. (4절 노트도 같은 누락이라 옮겨 적기 실수는 아님)
- 참고: 이 설정 분기는 점프표 0xd90c0 의 상황 0·1(c1f20)·7·8(c1f04, 이닝idx ≤ 5 조건 따로)에서만 탄다. 상황 2~5 는 설정과 무관한 다른 판정.
