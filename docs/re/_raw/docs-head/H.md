### H-1. 게임 모드 번호와 장면 (확정)
| 모드 | 뜻 | 시작(0x327b8) |
|---|---|---|
| 1 | 일반모드 | 진행 중 경기가 있으면 이어서, 아니면 "일반 모드를 진행하시겠습니까?" |

- **팀 능력치 적용**: 모드 2·8·9 에서만 (StrHOWTO[7] 과 일치)
- **경기 중 메뉴**(0x3c158) 칸: 일반·시즌·대전 [0,4,1,2,3] · 미션·홈런더비 [0,5,1,2,3] · 나리 [0,1,2,3,0]
  - 동작 4 = **자동진행**: 대전은 6회(0-기준 이닝 >5)면 거절(StrGAME[2]), 아니면 **100 G**(StrGAME[3]) / 그 밖 모드 **30 G**(StrGAME[4])
  - 동작 5 = **다시하기**(StrGAME[7]) — 미션·홈런더비는 자동진행 대신 이것
  - 동작 0~3 의 뜻(계속/설정/도움말/나가기 추정) 미확인
- 경기가 끝나면: 모드 2 → 시즌 관리 · 3·4 → 나리 관리 · 5·6 → 미션 선택 · 그 밖 → 메인 메뉴

### H-2. 홈런더비 (모드 7) — 규칙 전체 확정 · 웹 `mainMenu.ts:32` `isAvailable: false`
- 진입: 선수 고르기 창 결과 **2 = 육성 타자 · 4 = 명예 타자** (Q2 확정) → 모드 7
- **기회 10구** (+0x33). 던진 공 수 +0x68
- **비거리**: 결과가 홈런일 때만 `d = |착지점 − (20000, 1000, 30000)| / 265`, **한 타구 상한 160**, 누적 += d
- **마투수 등장**: 누적 비거리가 [800, 1200, 1600, 2000] 을 넘을 때마다 단계 +1
  - 단계 0: 일반 투수, **구질 1 고정**, 목표점 = 좌우별 존 중심 고정 (좌 (19415,1202,29705) / 우 (20585,1202,29705))
  - 단계 s ≥ 1: 마투수 표 [1,2,3,4][s−1] 번째 레코드를 상대 투수로 복사, **구질 22(마구)만**. 순서는 레오니 · 붕붕머신 · 발렌타인 · 드래고나 (유력)
- **콤보**: 직전 공과 이번 공이 모두 홈런이면 콤보 +1, 최대 콤보 갱신, **보너스 G += 콤보 × 5**. 아니면 콤보 0
- **이벤트 존**: 공이 날아가는 중 화면 y < 높이/3 이고 필드 플래그 +0x127 이 서면 그 자리에 존, 적중하면 **보너스 G += 200**. 존은 8프레임 주기로 깜빡 (`stadium/event_zone.pzx`)
- **보너스 게임**: 10구가 끝나고 최대 콤보 > 0 이면 **최대 콤보 수만큼** 추가 기회 (한 번만)
- **G** = `(누적 비거리 / 100) × [1,2,3,4,5][단계] + 보너스 G`, 99999 상한
- **최고 기록**: 저장 +0x5c(u16). 넘으면 갱신 + 신기록 효과음 0x1f (아니면 0x20)
- **HUD**(0x45a54): 일반 점수판 대신 공 아이콘 10칸, 공 번호 = (보너스 중 ? 최대콤보 : 10) − 남은 기회 + 1, 최고 기록과 비교해 넘으면 강조. 스프라이트 `ui/combo.pzx`, `ui/result.pzx`
- 끝: 예 → 홈런더비 재시작 / 아니오 → 메인 메뉴. 비거리 랭킹은 통신(없음)
- 웹 `pitchIntelligence.ts:39` "홈런더비(모드 7) 분기는 뺐다" → 구질 1 / 마구 분기 추가

### H-4. 필살타법(투수는 마구) 창 — 선택 규칙 확정 · `src/widgets/special-swing/ui/SpecialSwingWindow.tsx`
- 칸 4개, 기술 번호 = [1,2,3,4], **넷째 칸만 4 + 타입**(레코드 +0xb 상위 3비트)
- 이름: 타자 StrCOMMON[24+번호] → 1 파워 스윙 · 2 플레임 스윙 · 3 토네이도스윙 · 4 미라지 스윙(타격형) / 5 메테오 스윙(장타형)
  투수 StrCOMMON[30+번호] → 1 파이어 볼 · 2 웨이브 볼 · 3 썬더 볼 · 4+폼 → 샤이닝/캐넌/미라지 볼
- 확인 키: 이미 사용 중(레코드 +0x18 == 번호) → StrMODE[69] / 배운 수(+0x201) ≤ 칸 → StrMODE[71] "트레이닝 완료 후" / 아니면 StrMODE[70] "[이름]을 사용하시겠습니까?" → 사용 기술 = 번호
- 웹: 넷째 칸이 늘 "미라지 스윙"(`:77`), 칸을 "레벨"로 표시(`:66`), 기술 바꾸기 동작 없음 → 고칠 것
- **발동 조건·효과 수치는 미해결** (아래 3절)

### H-5. 스킬 장착 (확정) — 웹에 없음
- **마이너스 스킬은 해제 불가**: StrMODE[129] "[스킬] 스킬을 해제할 수 없습니다. 특별한 조건이나 [최면요법]으로 삭제 가능"
- 이미 장착 → StrMODE[131] "해제하시겠습니까?" / 여유 있음 → StrMODE[130] "사용하시겠습니까?"
- **최대 장착 수 [6, 8, 10]** (슬롯 단계 L = 저장 +0x1c6)
- 가득 찼을 때 확장: L=0 → "5000 G포인트를 소모하여 8개까지 확장하시겠습니까?" / L=1 → "10000 G … 10개" / L=2 → StrMODE[132] "동시에 최대 %d개…"
- 장착 수는 **스킬 번호 0~23 중 장착된 플러스 스킬**만 센다
- 창 그리기 좌표·색(0x81dc0)은 미해결 — 색 파랑/빨강/보라는 스킬 속성 비트로 유력
