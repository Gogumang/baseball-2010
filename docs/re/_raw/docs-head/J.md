### J-3. 경기진행 설정 (저장 형식·경기 루프 판정 확정, 화면 문구 대응 유력)
- 모드 칸 m: 일반 0 · 시즌 1 · 대전 2 (저장이 모드마다 따로)
- 종류: **0 찬스 · 1 이닝 · 2 상세**
- 경기 루프가 "지금 사람이 조작하나" 를 판정(0xc1e04):
  | 종류 | 값 | 사람이 조작하는 때 |
  |---|---|---|
  | 찬스 | 0 | **사람이 공격 중**이고 2루 또는 3루에 주자가 있을 때 (득점 찬스) |
  | 찬스 | 1 | **사람이 수비 중**이고 3루에 주자가 있을 때 (실점 위기) |
  | 이닝 | 0 | 늘 (전체) |
  | 이닝 | 1 | 4회부터 (= 6이닝) |
  | 이닝 | 2 | 7회부터 (= 3이닝) |
  | 상세(공격) | — | 현재 타자 타순 비트가 켜졌거나, 공격주자 비트의 루에 주자가 있을 때 |
  | 상세(수비) | — | 투수조작 이닝 비트(비트 8 = 연장, 유력)가 켜졌거나, 수비주자 비트의 루에 주자가 있을 때 |
  - 그 밖은 **자동 진행**
  - *(검증 V5 정정: 찬스 두 값이 보는 쪽이 공격/수비로 다르다 — 노트에서 빠져 있었음. 상태+9 = 공격 팀, +0xa = 수비 팀, +0x31+팀 == 0 이면 그 팀을 사람이 조작)*
  - 이 설정 분기는 상황 0·1·7·8 에서만 탄다 (7·8 은 0-기준 이닝 ≤5 조건 따로)
- 상세는 최소 한 항목(StrMAINMENU[126]), 확인 [125]
- 저장: +0x12c+m 종류 · +0x146+m 찬스/이닝 값 · +0x120+2m 타순 비트 · +0x124+2m 이닝 비트 · +0x128+m 공격주자 비트 · +0x12a+m 수비주자 비트

### J-4. 경기용 능력치 — 시즌·팀 부분 (확정) (나리 부분은 G-1)
- **팀 능력치 → 선수 능력치** (모드 1·2·8·9):
  ```
  T ≠ 0 이면 v += (17·T − 5100) / 100     ; = 0.17 × (T − 300), 0 쪽 버림
  투수: 구속·변화 ← 투구 / 제구 ← 집중 / 체력 ← 근성
  타자: 히트·파워 ← 타격 / 수비 ← 집중 / 주루 ← 근성
  ```
  예: 330 → +5 · 400 → +17 · 500 → +34 · 666(외인구단) → +62. 팀 능력치는 XlsTEAM_DATA 열 2~5
- **보직 불일치 수비 −20%** — **시즌모드에서만** 확인(0xb5844):
  - 내 팀 타자의 수비 칸, 스킬 21 "모든 포지션 수비 가능" 이 없을 때
  - 보직 bar 0 = 내야(자리 2~6), 1 = 외야(자리 7~9). 자리 0·1·10 은 면제
  - 마선수(마타자)는 면제
  - 설명서는 일반·대전도 벌점이 있다지만 코드는 못 찾음(미해결)
- **시즌 팀 상태**: 팀 질병 −30% / 팀 사기 **정액 감소** >50 없음 · 31~50 −50 · 11~30 −100 · ≤10 −200 (0 바닥). 나리의 비율 감소와 다르다
- **코치 보너스** (정액, 999 상한): 코치 0~9 = [8,9,10,6,4,8,5,10,6,7]
  | 코치 | 대상 | + |
  |---|---|---|
  | 0 | 투수 변화 | 8 |
  | 1 | 투수 구속 | 9 |
  | 2 | 투수 제구 | 10 |
  | 3 | 투수 제구·변화 | 6 |
  | 4 | 투수 전부 | 4 |
  | 5 | 타자 히트 | 8 |
  | 6 | 타자 수비·주루 | 5 |
  | 7 | 타자 파워 | 10 |
  | 8 | 타자 히트·주루 | 6 |
  | 9 | 타자 히트·파워 | 7 |
  - 팀 검사가 없어 **모든 팀 선수에 붙는 것으로 보인다** (유력 — 원본 동작이면 그대로)

### J-5. 시즌 구단관리 (확정)
- **코치채용**: 계약금 [1억, 1.5억, 2억, 2.5억, 3.5억] (마투수 줄 0~4 · 마타자 줄 5~9 같은 값), 필요 인기도 [0, 100, 300, 500, 1000]
  - 가드: 이미 이 코치 → [147] / 소지금 부족 → [77] / 인기도 부족 → [62] / 확인 [146] → 채용 [148]
  - 코치는 한 명, 바꾸면 새 계약금(환불 없음)
- **트레이드 성공률** (0xcf24):
  ```
  d = (내.등급 − 상대.등급) × 10 ; d < 0 이면 d ×= 2
  pen(타자 탭): 자리0 10 · 자리7 8 · 자리1·4 6 · 그 밖 0
  pen(투수 탭): 보직3 10 · 보직2·4 8 · 보직0 6 · 그 밖 0
  r = max(40 − |d|·100/250 − pen(내) − pen(상대), 3)
  r = min(r + [0, 50, 20][선택], 100)        ; 선택: 기본 0G / +50% 2000G / +20% 1000G
  성공: rand(1,101) < r   (실제 확률 (r−1)%)  또는 CPU 요청 수락이면 무조건
  ```
  - 트레이드는 구단관리 커맨드당 1회 (협회허가증으로 +1). 나리·명예의 전당 선수는 거절([165]/[166])
- **CPU 트레이드 요청**(관리 커맨드 차례마다): **10%**. 상대 팀 무작위(내 팀 제외), 탭 50%, 상대 선수 무작위(나리·명예 제외), 내 선수 중 **등급이 같거나 높은** 선수를 최대 8/12번 뽑아 요구. 알림 StrMODE[203]~[205]
- **팀 트레이닝**: 칸 0~3(투구·타격·집중·근성) 상승 4~6 · 사기 −6~8 / **지옥훈련 500G**: 네 능력치 각각 +7~10(따로 굴림) · 사기 −10~13. 서브 아이템 +2 · 자동안마기 사기 −1. 999 상한, 사기 0 이면 불가([193])
- **관중·수입** (경기마다):
  ```
  연승보정: ≤−7 −150 · −6~−4 −100 · −3~−2 −50 · −1~3 0 · 4~5 +50 · 6~7 +100 · 8~9 +150 · ≥10 +200
  p = 평판 + 연승보정
  10경기 이하: p += 100 / 그 밖: p += 내순위[120,100,80,60,40,0,−10,−20,−30,−40] + 상대순위[100,80,60,40,20,0,0,−10,−20,−30]
  p += 150
  관중 = max(p,1)/5 × 120 + 전광판[0,2,3,4,5,5,5]×1000 + 4000
  관중 = max(min(관중, 관중석[20,25,30,35,40,40,40]×1000), 3000)
  수입(100만 단위) = (관중/20)·15/1000 (+2 구내매점), 0~9999 → 소지금에 더함   ; 1명당 7500원
  만원 단계: ≥80% → 2, >35% → 1, 그 밖 0
  ```
- **구장 아이템**:
  | 종류 | 이름 | 효과 | 가격(100만 단위, 유력) |
  |---|---|---|---|
  | 관중석 | 1단·2단·3단·4단·트로피컬·콜로세움·스페이스 | 수용 20·25·30·35·40·40·40 천 명 | 0·200·500·800·1000·1000·1000 |
  | 전광판 | 소형·중형·대형·초대형·내추럴·고대의·싸이키 | 관중 +0·2·3·4·5·5·5 천 명 | 0·100·400·700·900·900·900 |
  | 잔디 | 4종 | 설명 문구만 | — |
  - 히든 4~6 그림 = `stadium/hidden_fence_0~2` · `hidden_board_0~2` (컬렉터로 열림, 유력). 일반모드 구장 선택 그림이 **아니다**
- **10년차 엔딩** (연차 idx 9 에서만):

## 2. 원본 버그 — 그대로 옮기고 나중에 수정 후보
- **빠른실행에서 같은 팀끼리 경기가 나올 수 있다** (재추첨 없음)
- **트레이드 성공률이 등급 차의 절댓값**을 쓴다 — 더 좋은 선수를 내줘도 확률이 떨어진다
- (확인 필요) 코치 보너스가 상대 팀 선수에게도 붙는 것으로 보인다

## 3. 미해결
- 일반·대전모드의 보직 벌점 위치
- 투수 등판 판정(선발 2경기·구원 8회), 강판(평판), 스태미나 소모식, 구질 훈련 횟수 표
