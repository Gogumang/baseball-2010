### C-2. MPL 파일 포맷 (확정 — 모든 파일 파싱 성공)
```
첫 바이트 h: 윗 니블 = 종류, 아래 니블 ≠ 0 이면 팔레트 뒤 u32 하나 더 (실제 파일은 전부 0)
h>>4 = 3 (RGB565) / 2 (RGB 3바이트) — 통팔레트:
    u8 개수N | u32 절대오프셋 × N | 팔레트 × N
    팔레트 = u8 색수(0=256) | 색 × 색수
h>>4 = 4 — 이미지별 변형 (0x40):
    u8 0x40 | u16 개수N | u16 이미지번호 × N | u32 절대오프셋 × N | 묶음 × N
    묶음 = u8 변형수K | (u8 색수 | u16 RGB565 × 색수) × K
```

|---|---|---|---|
| bat/batter_balancer · batter_sluger | 0x30 | 45 × 82색 | 피부×15+팀 |
| bat/batter_helmet | 0x30 | 15 × 26 | 팀 |
| pitcher | 0x30 | 45 × 41 | 피부×15+팀 |
| defender | 0x30 | 15 × 48 | 팀 |
| event_char_0 | 0x30 | 3 × 239 | 팔레트 0·1 = 주인공 피부, 2 = 인물 8·9 |
| ui/game_ui | **0x40** | 이미지 8(4색)·9(3색) 에 변형 8개 | PZX 효과 5~0x64 |
| ui/mode_ui | **0x40** | 이미지 0·1 변형 7, 31 변형 1 | PZX 효과 |

### C-3. PZX 파트 효과 0x05~0x64 (확정) — `tools/decode_pzx.py` 가 무시 중
- 효과 0x05+n = **붙은 0x40 mpl 에서 이 파트 이미지의 n번째 변형 팔레트**로 칠한다 (0xc8bb4, `subs r2,#5`).
- 쓰이는 곳은 mode_ui(이미지 0·1·31)·game_ui(이미지 8·9) 뿐 — **UI 상태색**(선택/비활성). 예: mode_ui 31 변형 = OK 버튼 파랑 → **주황**.
- 관리 화면의 "선택 칸 주황" 은 이 변형이다. `tools/generate_management_sprites.py` 가 따로 만든 주황과 같은 색인지는 미대조.
- 효과 1~4: 1 → +0x18 · 2 → +0x1c · 3 → 좌우 뒤집기 · 4 → 상하 뒤집기.
- 0x66/0x67/0x6E/0x6F/0x7E 는 그리는 단계에서 처리 (0x7E 는 **미해결**).

### C-4. 선수 등록 화면 (확정)
- 흐름: 0x65 팀 고르기 → 0x66 등록 → 0x67 확인(같은 화면 위 StrMODE[2] 메시지 상자)
- 목록 5개:
  | 줄 | 목록 | 선택지 | 레코드 반영 |
  |---|---|---|---|
  | 0 | 이름 | — | — |
  | 1 | 타입 [0x7c] | 타자 2(타격형/장타형) · 투수 3 | rec[0xb] bit5-7 |
  | 2 | 포지션/보직 [0x78] | 타자 내야/외야 · 투수 선발/구원 | rec[0xb] bit0-1 (투수가 1 고르면 2 저장) |
  | 3 | 손 [0x80] | 우/좌 | rec[0xb] bit4 |
  | 4 | 피부 [0x84] | 황인/백인/흑인 | rec[0xb] bit2-3 |
- **타순 선택은 없다** (확정). 정보 칸의 타순은 표시 전용, 신인 9번은 나만의리그 초기화(0xa4c2c).
- rec[0xa]: 등록 타자 0xa0 / 투수 0x80 (bit7 = 내 육성 선수)
- 줄 1·3 을 바꾸면 그림 다시 적재, 줄 4 는 팔레트만 교체, 줄 1·2 는 능력치 다시 계산
- 시작 능력치 (0x16e2c):
  ```
  타자: out[i] = 표 0xcc3fa[타입*4+i] × 10     ; 타격형 [10,10,10,10] · 장타형 [8,15,8,8]
        내야 → out[2](수비) += 30, 외야 → out[3](주루) += 30
  투수: out[i] = 표 0xcc3f2[min(보직,1)*4+i] × 10 ; 선발 [10,10,10,20] · 구원 [12,12,12,10]
        타입 0 → out[1] += 30 · 타입 1 → out[0] += 30 · 그 밖 out[2] += 30
  각 값 999 상한
  ```
  타자는 웹 `playerCareer.ts:166 rookieAbilityOf` 와 같다. **투수 표는 투수편 구현 때 사용**.

### C-5. 좌타/우타 → 타석 배치 (확정, 한 고리 유력)
- side = rec[0xb] bit4 = 등록 화면 손 선택. **0 우타 → side0 · 1 좌타 → side1**
- 그림 객체 +0x3c 와 타석 판정 0xab214 가 이 값을 쓴다.
- 웹: side 를 1 로 고정 (`RALPH_PROGRESS.md:749`) → `career.battingSide` 를 그대로 넘기도록 고칠 것.

### C-6. 등록 화면 배치 (확정, 화살표 세부 유력)
