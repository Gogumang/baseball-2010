## 1. 구현 명세 — 웹을 원본대로 고칠 것

### G-1. 경기용 능력치 감소 순서 (0xb570c, 확정) — `src/entities/career/model/condition.ts:41-52` ⚠️
```
v = 0xb6414(선수, 칸, 1)          ; 마선수 배율 → 장비 보너스 → 스킬 보정 (이 순서)
if 나만의리그(모드 3·4) and 내 선수(+0xa bit7):
    if 질병:  v += (−30·v) / 100
    if 부상:  v += (−60·v) / 100     ; 둘 다면 둘 다 차례로
    사기 >50  : 그대로
    사기 31~50: v += v / (−10)       ; −10%
    사기 11~30: v += v / (−5)        ; −20%
    사기 ≤10  : v −= v / 2           ; −50%
나눗셈은 0 쪽 버림
```
- 웹: 부상/질병 중 **하나만**, **장비 보정 전**에 곱하고, **사기 감소가 없다** → 세 가지 모두 고칠 것
- 안내문 StrMODE[213] "사기가 낮아 선수 능력치가 %d 감소하였습니다"
- 뒤이어 인자 [sp+0x24](체력 계열로 보임) 구간 감소 35~54 −10% · 20~34 −30% · 1~19 −50% · ≤0 −90% — 타자편 값 미해결 (투수편 체력일 가능성)

### G-2. 부상 누적 엔딩 (확정 — B 와 교차 확인) ⚠️
- 경기마다 부상 중이면 `+0x1b6 += 1` (부상 상태로 치른 경기 수). 부상 기간은 경기로 줄지 않는다(휴식·입원으로만)
- 회복·5000G 이어하기 때 0
- `+0x1b6 > 19` 면 엔딩 0 (B-6·B-7)

### G-3. 외출 가드 순서 (0x16cf0, 확정) — `outing.ts:23-36`

### G-4. 외출 빈 장소는 행동을 쓰지 않는다 (확정)

### G-5. GP 능력 아이템 (0xa4488, 확정) — `gpItems.ts:55-64`
- 한계 표: 타자 [80,80,80,80 | 80,85,75,75]×10 (행 = 타입) · 투수 [80,80,80,80 | 85,85,85,60]×10

## 2. 원본 버그 — 그대로 옮기고 나중에 수정 후보
- **GP 능력 아이템 알림 숫자**: 실제 +10 올리면서 "히트 **6** 상승하였습니다" / "모든능력치 **8** 상승하였습니다" 라고 표시 (인자 6·8 이 글에 찍힘). 웹은 "+10" 표시 중 → 원본대로 6·8 로
- **보험증서 무시**: 외출 소지금 검사가 보험증서를 보지 않아 소지금 200만 미만이면 입원이 막힌다
- **필살타법 최고 레벨 가드 없음**: 레벨 4 에서 표 밖 값(필요 380회·비용 0)을 읽는다. 웹 '훈련완료' 차단(`training.ts:87-89`)은 우리가 넣은 것 — 원본대로면 제거. 단 필살타법 창(상태 0x6c)에서 막는지는 미확인
