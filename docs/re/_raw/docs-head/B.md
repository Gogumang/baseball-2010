### B-3. MVP (시즌 MVP, 확정)
```
MVP = (타이틀 ≥ 1) AND (타이틀 3개 모두 OR 올해의 목표 달성 수(단계 2) ≥ 4)
```
- 단계 2 = 목표치 5개 모두 **+trunc(g·10/100)** 상향(투수는 방어율·+0x22 만 −10%)
- MVP 면 `career+0x1ca |= 1 << 연차idx` (연도별 MVP 비트, 통산 MVP 수 = 비트 수)
- MVP 가 아니면 내가 못 딴 첫 타이틀의 수상자를 MVP 로 보여 준다
- 웹: `app/model/seasonEvents.ts:29` `TITLE_RANK = 0`, MVP 없음

### B-5. 연봉 (확정)
- 저장 u16 +0x1c8, **100만원 단위** (신인 50 = 5000만). 표시 = ×100 만원: 9999 이하 `"%d"`, 넘으면 `"%d억"` / `"%d억%03d"` → 50 → "5000만", 150 → "1억5000만"
- 제시 상승분 = `max(1, (인기도 − career+0x78) / 4)` (0 쪽 버림), 새 연봉 = 상승분 + 현재
- **강경/정중 결과는 확률이 아니다** — 등급 k = 0xa4d78:
  - 타자: 홈런·타점·타율 1위가 내 선수면 각 +1 / 투수: 다승(세이브)·탈삼진·방어율
  - **올해 MVP 비트면 +2**
  - k==0 → 강경 387(−20% 평판−30) / 정중 391(−10% 평판−20)
  - k≤2 → 386(+10% 평판−20) / 390(+5% 평판−10)
  - k≤4 → 385(+20% 평판−10) / 389(+10%)
  - k=5 → 384(+30%) / 388(+20%)
  - 수락 383: +0% 평판+20
- 새 시즌 0x1b768: 국가대표 플래그 0 · 연차+1 · 사기 100 · **소지금 = clamp(소지금 + 연봉, 0, 9999)** · 지난 시즌 기록을 연도별 칸에 복사
- 웹: `seasonFlow.ts:147 salaryResultEventId` 구간은 같다. **`seasonEvents.ts:29` 가 k=0 고정** → 강경은 늘 387, 정중은 늘 391 → 고칠 것
