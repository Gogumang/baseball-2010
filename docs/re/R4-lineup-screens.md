## 1a. 사람 교체 — 여는 곳·키 처리·실행 — **확정**
**정정**: 0x49598 은 "교체 메뉴" 가 아니라 **교체 예약 한 줄 함수** 다. 메뉴의 키 처리는 바로 뒤 **0x495fc** (경기 장면 프레임 0x52c50 이 경기 상태 0xb 일 때 부른다, `52dbe: cmp r3,#0xb → 52de0: bl 0x495fc`).

**0x49598(scene, k)** — 사람 쪽 팀 하나에 벤치 k 번을 예약:
```
495a4: r1 = s8 state[9](공격팀) ; state[0x31+공격] == 0 (공격이 사람) ?
495bc:   → 0xaf06c(scene[0x228+4×공격], k, 0)   ; 대타 예약: team+0x291=1, team+0x293 = 9+k
495d0: 아니면 0xaf09c(scene[0x228+4×수비(state[0xa])], k, 0) ; 투수 예약: team+0x290=1, team+0x292 = k+1, 메시지 0xbbf
```
(state = [0x1552d0c]. 셋째 인자 0 = 지금 확정하지 않음. ≠0 이면 0xaebe4(team,1) 로 바로 확정.)

**여는 곳** 0x498d4 의 '#' (0x4994a~0x499f6):
- 0x38984 참, 경기 상태 [scene+0x1c] ∈ {0xe, 0xf}.
- 모드 [scene+0x1104] == 3(나리 투수편) → 0x702b5 로 StrGAME[0x68=104] 질문 창 + 0xbbef9(…,2,0x1b,1). 교체 화면 없음.
- 그 밖: 벤치 수 n = 공격이 사람이면 u8 team[+0x28c](벤치 타자) / 수비가 사람이면 u8 team[+0x33](벤치 투수) (둘 다 사람이면 수비 값이 이긴다). n > 0 이면 `0x49598(scene, 0)` (벤치 0번 미리 예약) → 경기 상태 **0xb** 예약(0xbcb49).

**키 처리 0x495fc(scene)** (키 = [scene+0x40], skin = [0x1552cfc]):
| 키 | 동작 |
|---|---|
| '2' → −1(위), '8' → −2(아래) 로 바꿔 읽음 (0x49608~0x49618) | 목록 객체 scene+0xf58 의 키 처리 0x6c299 (커서 이동) |
| OK(−5 또는 '5') | 상세 창이 열려 있으면 닫고, **커서 idx = 목록[+0x10]×[+0x14]+[+0xc]** 로 `0x49598(scene, idx)` 재예약 → 경기 상태 **0x16**(교체 연출) (0x496f0~0x4970c) |
| '0' | 상세 창 토글 skin+0x424 (켜질 때 +0x425=0, +0x426=1, 창 x = W/2+0x52−폭/2 (+0x428), +0x42c = W/2+0x52, y = H/2−0x65 (+0x42e), +0x430=7, +0x432=0xcb). 닫힐 때 [skin+0xd8]+0x1e3 = 0 |
| '#' 또는 CLR(−16) | 상세 창 닫고 경기 상태 **0xe** 로(취소), 두 팀 모두 `0xae989(team)` = team+0x290·+0x291 = 0 (예약 지우기) |
| 위·아래 이동 중 상세 창이 열려 있으면 | [skin+0xd8]+0x1e3 = 0 (0x49626~0x49638, 키 −1·−2 에서만) |
- **교체는 # 를 누른 쪽이 사람이면 공격 중 = 대타, 수비 중 = 투수 교체 하나뿐.** 야수 교체·대주자·수비 위치 변경 메뉴는 없다(Q1 4 와 같음).
- 한 경기 대타 횟수 제한은 사람에겐 없다(벤치 수만 본다). CPU 대타만 state[0xe] 로 경기당 1번.

## 1c. 교체 확정 — **확정**(투수 E 3c, 대타 여기) / 기록 칸 뜻 **유력**
확정 함수 0xaebe4(team, 즉시) (다음 타석 시작 0xc262c 첫머리 또는 즉시 플래그):
- 투수(+0x290): team[0] ↔ team[team[0x292]] 맞바꿈, 벤치 투수 수 team+0x33 −1 (E-3c).
- 대타(+0x291, +0x293 ≥ 9 일 때 0xaecac~0xaedec):
  1. 새 타자가 옛 타자의 수비 위치 니블을 받는다: `0xb8a35(team, 선수idx)` 로 선수 레코드를 얻어 [+0x1c]&0xf 를 서로 바꿔 넣음(0xb8e85(rec, pos, 1)).
  2. 명단 team[0xe + 타순슬롯] ↔ team[0xe + 벤치idx] 맞바꿈 (aed02~aed14).
  3. 0xb95b1 로 명단 뒤쪽을 한 칸 당겨 **빠진 선수를 벤치에서 지운다**(재출장 불가). 타순별 경기 기록(24바이트, team+0x34+슬롯×0x18)도 맞바꾸고 같은 식으로 당긴다(aed2c~aed98).
  4. 벤치 타자 수 u8 team[+0x28c] −1(0 밑으로 안 감) (aed9c~aedae).
  5. team[+0x298] 이 있고 즉시 플래그 0 이면 메시지 0xbbe(인자 = 새 타자가 마선수인가 0xb633d) (교체 연출/해설 쪽, 유력).
  6. 0xae9e8(team, −1) 호출, team+0x297 = 1 (뜻 미확인).
- 웹판: 교체 기능 없음(grep "substitut|pinch|대타" in src/ → 0건 확인은 5절).

| 필드 | 뜻 |
|---|---|

키:
- **'*'**: 탭 토글, 고른 줄 취소(+0x418 = −1, +0x330 이 −1 이 아니면 0 으로).
- **CLR**: 고른 줄이 있으면 취소, 없으면 +0x338 = 1(나가기).
- **왼(−3·'4')/오른(−4·'6')**: 타자 탭에서 고른 줄이 없을 때 하위 탭 0 ↔ 1 이동, 끝을 넘으면 +0x338 = 2/3. 투수 탭은 바로 2/3.
- **'0'**: 상세 창.
- 위·아래: 이 함수가 안 받는다(목록 객체 쪽 — 부른 쪽이 넘김, 유력).
- **OK(−5·'5')** (+0x330 == −1 이면 무시):
  1. 커서 선수 = 투수 탭 0xb51fd(팀, idx) / 타자 탭 0xb53d1(팀, idx). **마선수(0xb633d)면 StrTEXT "마선수는 엔트리를!N바꿀수 없습니다"(0xd200c) 팝업 0x74ef5** 하고 끝 (0x55bee).
  2. 첫 선택이 없으면 +0x418 = 커서. 단 **수비위치 하위 탭(1)은 커서 ≤ 8(선발 9명)만** 고를 수 있다.
  3. 같은 줄을 다시 누르면 취소.
  4. 다른 줄이면: 투수 탭 → `0xb5e99(팀, 첫, 둘, 1)` · 타순 탭 → `0xb5e99(팀, 첫, 둘, 0)` · 수비 탭 → 둘 ≤ 8 일 때만 `0xb5fe5(팀, 첫, 둘)`. 그 뒤 +0x418 = −1.
  - 마선수 검사는 OK 처리 맨 앞에서 **커서 줄**에 한다(0x55b22·0x55be2) → 첫 선택이든 둘째 선택이든 마선수 줄에서 OK 하면 막힌다. 즉 마선수는 자리를 절대 못 바꾼다.

**교환 함수** (선수 레코드 48바이트, 타자 배열 [팀+0x18], 투수 배열 [팀+0x14]):
- `0xb5e99(팀, a, b, 투수?)`
  - 투수: 레코드 a ↔ b 통째로 맞바꿈 (0xb5f5a~). → 투수 목록 순서가 바뀐다. 투수 0번 = 경기 첫 투수(E-3c team[0])이므로 **투수 탭에서 0번 줄과 바꾸는 것이 곧 "선발 변경"**(확정: 경기정보 "선발" 줄이 투수 0번 이름을 보여 준다 — 2d).
  - 타자: 레코드 a ↔ b 맞바꾼 뒤 수비 위치 니블(+0x1c & 0xf, 0 = 벤치)을 정리:
    - 둘 다 선발(위치 ≠ 0) → 위치는 **선수를 따라간다**(타순만 바뀜).
    - 한쪽이 벤치(위치 0) → 위치는 **자리에 남는다**: 벤치에서 올라온 선수가 내려간 선수의 수비 위치를 받고, 내려간 선수는 0(벤치).

    ```
    b5ec4: pa = rec[a].+0x1c & 0xf ; pb = rec[b].+0x1c & 0xf ; memcpy 로 a↔b
    b5f10: if pb==0 or pa==0: set_pos(rec[a], pa); set_pos(rec[b], pb)   ; 자리 기준
    b5f32: else:              set_pos(rec[a], pb); set_pos(rec[b], pa)   ; 선수 기준
    ```
- `0xb5fe5(팀, a, b)` 수비 탭: 둘 다 위치 ≠ 0 일 때만 **위치 니블만 맞바꿈**(타순 그대로) (0xb6010~0xb602a).
- 보직(선발/중계/마무리, 투수 레코드 +0xb 하위 2비트)을 바꾸는 코드는 이 편집기에 없다 — 투수는 목록 순서만 바뀐다(유력: 0x55724 목록 채우기와 그리기에서 보직 칸을 안 봤음).
- 웹판: 엔트리 편집 없음(5절).

### 3c. 준비 기록을 받아 경기를 세우는 곳 `0x30f20` — **확정**

경기 장면(0x104)이 서면서 `[[장면+0x120]+0xbc]` 16바이트 `rec` 를 지역으로 통째로 복사하고
(`30f2c~30f46`) 팀 객체 둘(각 `0x29c` 바이트, `alloc 0x1238` → ctor `0xae800`)을
`[장면+0x140]`·`[장면+0x144]` 에 만든다. `rec+8`(사람 쪽)이 어느 칸이 사람 팀인지를 정한다 —
`r5 = 장면 + 0x140 + rec[8]×4`(사람), `r4 = 장면 + 0x140 + (1−rec[8])×4`(AI).

```
31018: 0xb891c(사람팀, [장면+0x13c], rec+0(유저 팀), rec+8)      ; 팀 채우기 (P1 1-1)
31030: 0xb891c(AI팀,   [장면+0x13c], rec+4(AI 팀),  1−rec+8)
31042: 0xb88c8(사람팀, u8 rec[0xe])   ; 마투수 — 되면 team[+0x26]++, team[+0x33]++
3104c: 0xb8870(사람팀, u8 rec[0xd])   ; 마타자 — 되면 team[+0x27]++, team[+0x28c]++
31058: v = 0x66968(u8 rec[0xe])       ; ← 난수 1
31064: 0xb88c8(AI팀, v)               ; AI 마투수
3106c: w = 0x66994(u8 rec[0xd])       ; ← 난수 2
31076: 0xb8870(AI팀, w)               ; AI 마타자
3107a: 0xb8c94(AI팀,   0, bfa55(0,4)) ; ← 난수 3  AI 선발 (로스터 앞 4명 중 하나)
31090: 0xb8c94(사람팀, 0, bfa55(0,4)) ; ← 난수 4  사람 선발
```
- **`0x66968`(마투수) 과 `0x66994`(마타자) 는 바이트 단위로 똑같은 함수다** (리터럴도 둘 다 `0xbfa55`):
  ```
  f(내_번호):
    v = bfa54(0, 5)                  ; 6696e~66978  → 0~4 (rand 는 위끝 제외)
    if v == 내_번호:                  ; 6697c       인자는 ldrb 로 들어온다
        v = (v != 0) ? v − 1 : 4     ; 66980~66988
    return v
  ```
  곧 **사람이 고른 번호와 겹치지 않는 0~4 한 장**이다.
- ⚠️ **원본 버그**: 인자를 `ldrb`(부호 없음)로 읽어 사람이 "없음"(−1)을 골라도 `v == 0xff` 가
  절대 성립하지 않는다 → **사람이 마선수를 안 써도 AI 는 늘 마투수·마타자를 하나씩 얻는다.**
- 마선수 표는 `0x1f824`(마투수) · `0x1f84c`(마타자) 가 꺼낸다 — 둘 다 번호를 `[0,4]` 로 **자르고**
  `[전역+0xac] + 번호×0x30 + 0xc64`(투수) / `+0xd54`(타자) 를 돌려준다. 두 표는 **맞붙어 있다**
  (0xc64 + 5×0x30 = 0xd54) → 각 5명, 0x30바이트 레코드.
- **난수 차례는 마투수 → 마타자 → AI 선발 → 사람 선발 넷이다.** 옮길 때 이 차례를 지켜야 한다.
- 웹판: `entities/game/model/aceOpponent.rollOpponentAceIndex` + `play-team-game/teamGameFlow.startTeamGame`
  (`opponentAceIndexesOf` 가 `startingPitcherSlotsOf` 보다 먼저 돈다). AI 마타자는 벤치 첫 칸에
  들어가 CPU 대타(Q1 4절)로 타석에 설 수 있다. **AI·사람 마투수를 벤치 투수로 넣는 `0xb88c8` 은
  아직 안 옮겼다** — 웹 투수 명단이 로스터 8칸 붙박이다.
