## 요약

**남은 것**: 0x20 에 들어오는 길(못 찾음), 0x18·0x21·0xc 그림의 img_text 번호(388·389·329, 0xb9, 0xc1·0x86)가 무슨 글자인지(그림 확인 안 함), 0x3b80c 띠 9단계의 칸별 좌표, 0x21 속도 칸·안내 띠의 정확한 좌표, 0x13 의 +0x199a 뜻, 0xae3e8(B) 의 세부 가지(견제 가지는 I-controls 4a-3 에서 풀림), 0x10 메시지 8 두 가지의 뜻. 0x13·0x12 그리기의 공 부분은 궤적이라 읽지 않았다.
